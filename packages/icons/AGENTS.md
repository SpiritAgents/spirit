# Spirit Icons — Package Guidelines

`@spiritagent/icons` publishes React icon components. `icons/*.svg` + `icons/*.json` are the single source of truth; everything under `src/icons/`, plus `src/index.ts` and the package `exports` map, is generated by `scripts/build-icons.mjs` and gitignored. Never hand-edit generated files.

To add an icon: add one `icons/<name>.svg` + `icons/<name>.json` pair, then run `pnpm --filter @spiritagent/icons build`.

## Visual Style

- Modern App/SaaS style: clean geometry, no decorative detail.
- 24×24 grid, stroke-based: the root carries `fill="none"`, `stroke="currentColor"`, `stroke-width="2"`, round linecap/linejoin. Design at stroke-width 2.
- Corner radius system: `rx=3` (frames, squares, panels).
- Safe area: keep all ink inside the grid with margin — typically coordinates 2..22, or 3..21 for framed shapes. Standalone glyphs must not bleed; a glyph that deliberately overflows its frame inside a composite icon (the compose pencil) is the exception, not the rule.
- Negative-space occlusion gap: when shapes overlap in depth (compose's pencil over its frame, copy's stacked squares), truncate the rear shape with a ~2px gap (same magnitude as the stroke) instead of crossing lines. The gap reads as the front shape's hidden thickness.
- Natural truncation: when an endpoint lands on or near a corner, let the corner radius complete naturally or transition with a Bézier shoulder (see the compose pencil tip); never cut a corner abruptly.
- Derive directional variants by rotating a single glyph (the chevron family).
- Solid variants reuse the outline path with an element-level `fill="currentColor" stroke="none"` override on the root defaults (spirit vs spirit-outline).

## Naming

- File names are kebab-case (`loader-circle`, `sidebar-left-collapsed`); component names are the PascalCase form (`LoaderCircle`, `SidebarLeftCollapsed`).
- Name by our own semantics, not another library's: `gear` (not settings), `compose` (not square-pen), `x` (not close).
- Variant suffixes: `-collapsed`, `-outline`, …
- `<name>.json` holds `{"tags": [...]}` — search keywords; English terms only. Localized tags require a real localization mechanism, which is future work — do not add per-language tags by hand.

## Source Conventions (enforced by `scripts/verify-icons.mjs`)

- One icon = one `<name>.svg` + one `<name>.json` pair.
- The SVG root carries exactly the nine default attributes; only whitelisted self-closing elements (`path`, `rect`, `circle`, `line`, `polyline`, `polygon`); double-quoted attributes; color values limited to `currentColor`/`none`; no external references.
- `pnpm --filter @spiritagent/icons test` runs the verifier standalone.

## Commit Discipline

- One commit per icon. Never bundle two or more icons into a single commit.
- Factory, scaffolding, and other package-level changes land in their own commits at the same granularity.
