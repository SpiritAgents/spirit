# @spiritagent/ui

Shared React primitives for Spirit desktop and the marketing site. Apps supply theme tokens; this package supplies controls, overlays, and motion.

## Requirements

- Node.js 26.13.0
- React 18+
- Tailwind CSS v4 (scan `src` with `@source` and import `theme.css`)
