---
title: Appearance
description: Theme, fonts, and the ten UI languages.
---

Open **Settings → Appearance**.

## Theme

`system`, `light`, or `dark`. Stored as `spirit-desktop-theme`.

## Font

Default is the system font. You can switch to a custom family.

## UI languages

The Desktop / CLI UI has **ten** languages. The default is Simplified Chinese.

| Code    | Language            |
| ------- | ------------------- |
| `zh-CN` | 简体中文 (default)  |
| `en`    | English             |
| `zh-TW` | 繁體中文            |
| `ja`    | 日本語              |
| `ko`    | 한국어              |
| `de`    | Deutsch             |
| `fr`    | Français            |
| `es`    | Español             |
| `pt-BR` | Português do Brasil |
| `ru`    | Русский             |

Other appearance toggles (mica / blur, pointer) stay on the same settings page.
