---
title: Integrations
description: GitHub Device Login. The token goes in the keyring.
---

**Settings → Integrations** connects GitHub with the OAuth device flow. You approve in the browser; {{product.name|mdx}} stores the token in the system keyring under the `{{product.name}}` service.

The full panel is available in the Electron app. Other shells may show a limited notice.

GitHub is required before [Automations](./automations.mdx) can trigger on pull requests or issues. Disconnecting GitHub removes that trigger path; existing time automations keep running.
