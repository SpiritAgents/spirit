Rules are Markdown the agent always considers. There are three slots:

| Scope                    | Path                      |
| ------------------------ | ------------------------- | --------------------------------------------------------- |
| Workspace agents file    | `{workspace}/AGENTS.md`   |
| Workspace {{product.name|mdx}} rule                | `{workspace}/{{product.workspaceDataFolderName}}/rule.md` |
| User rule                | `{spiritDataDir}/rule.md` |

Write project conventions in `AGENTS.md` so anyone who opens the repo sees them. Use `{{product.workspaceDataFolderName}}/rule.md` for {{product.name|mdx}}-specific notes you do not want in the generic agents file. Use the user rule for preferences that follow you across workspaces.

Manage slots in **Settings → Rules**. A built-in Skill, `create-rule`, can draft a rule file for you. A rule bundled in an [extension](../develop/extensions.mdx) applies when that extension is enabled. It does not appear in this settings list.
