---
title: Desktop 설치
description: macOS, Windows, Linux용 Spirit를 다운로드하세요.
---

Desktop은 그래픽 호스트입니다: 채팅, 작업 공간 파일, Git, 설정, 확장 프로그램, 자동화 기능을 제공합니다. [CLI](./cli.mdx)와 로컬 데몬을 공유합니다.

## 다운로드

[다운로드 페이지](/en-US/download)를 사용하세요. OS와 아키텍처에 맞는 빌드를 `download.spirit.fast`에서 선택합니다.

| 플랫폼  | 파일          | 아키텍처         |
| ------- | ------------- | ---------------- |
| macOS   | `.dmg`        | x64, arm64       |
| Windows | `.exe` (NSIS) | x64, arm64, ia32 |
| Linux   | `.AppImage`   | x64, arm64       |

[최신](https://github.com/SpiritAgents/spirit/releases/latest) GitHub 릴리스를 사용할 수도 있습니다. Linux 릴리스에는 AppImage 외에 `.deb`가 포함될 수 있습니다.

Desktop용 공식 Homebrew, winget, apt 패키지는 없습니다.

## 설치 후

1. Spirit를 엽니다.
2. [작업 공간 열기](../quickstart.mdx#2-open-a-workspace).
3. **설정 → 모델**에서 공급자를 연결하세요. 키는 시스템 키링에 저장됩니다.

macOS에서 Gatekeeper가 첫 실행을 차단하면 Finder에서 Control-클릭 → 열기로 앱을 실행하세요.

Linux에서 AppImage를 실행하기 전에 실행 권한을 부여하세요 (`chmod +x Spirit-linux-*.AppImage`).

## 업데이트

다운로드 페이지와 CDN `latest` 경로는 항상 현재 Desktop 빌드를 가리킵니다. GitHub 릴리스는 특정 버전을 고정해야 할 경우 버전별 자산을 유지합니다.
