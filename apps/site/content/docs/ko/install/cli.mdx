CLI는 TUI와 비대화형 `-p` 모드를 갖춘 터미널 호스트입니다. [Desktop](./desktop.mdx)과 동일한 로컬 데몬과 통신합니다.

## 설치 스크립트

macOS 및 Linux:

```bash
curl -fsSL {{product.websiteOrigin}}/install | bash
```

Windows (PowerShell):

```powershell
irm {{product.websiteOrigin}}/install.ps1 | iex
```

스크립트는 `{{product.downloadOrigin|host}}`에서 빌드를 다운로드한 뒤, 같은 GitHub Release의 `SHA256SUMS.txt`로 SHA-256을 검증합니다(불일치 시 중단). 통과하면 압축을 풀어 `spirit`을 `PATH`에 추가합니다.

새 터미널을 연 다음:

```bash
spirit --version
```

## 설치 위치

CLI 바이너리는 SPIRIT_HOME을 사용합니다. Unix에서는 Stable 설치와 공유 데이터가 같은 상위 디렉터리를 사용할 수 있지만 bin/과 cli/는 설치 파일입니다. 설치 설정은 공유 데이터 디렉터리를 결정하지 않습니다.

|                         | 기본값                                                                                                       | 재정의            |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------- |
| CLI 바이너리            | Unix: `~/.spirit` · Windows: `%LOCALAPPDATA%\Spirit`                                                         | `SPIRIT_HOME`     |
| 세션, 구성, 키링 포인터 | Stable: `~/{{product.stable.userDataFolderName}}` · Dev: `~/{{product.dev.userDataFolderName}}` · Windows: `%USERPROFILE%\{{product.stable.userDataFolderName}}` / `%USERPROFILE%\{{product.dev.userDataFolderName}}` | `SPIRIT_DATA_DIR` |

Unix에서 스크립트는 `$SPIRIT_HOME/bin/spirit` → `$SPIRIT_HOME/cli/current/bin/spirit` 링크를 만들고 `~/.profile`, `~/.bashrc`, `~/.zshrc`에 `export PATH="$SPIRIT_HOME/bin:$PATH"`를 추가합니다 (마커 `# spirit cli`).

## 버전 또는 미러 고정

| 변수                   | 기본값                                   | 역할                         |
| ---------------------- | ---------------------------------------- | ---------------------------- |
| `SPIRIT_HOME`          | `~/.spirit` 또는 `%LOCALAPPDATA%\Spirit` | CLI 바이너리 설치 루트       |
| `SPIRIT_VERSION`       | `latest`                                 | 다운로드 URL의 버전 세그먼트 |
| `SPIRIT_DOWNLOAD_HOST` | `{{product.downloadOrigin|host}}`                    | CDN 호스트                   |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL {{product.websiteOrigin}}/install | bash
```

[다운로드 페이지](/en-US/download)나 [GitHub Releases](https://github.com/SpiritAgents/spirit/releases/latest)에서 CLI 아카이브를 직접 다운로드하여 압축을 풀 수도 있습니다.

## 첫 실행

```bash
cd /path/to/your/project
spirit
```

그러면 TUI가 열립니다. `/model add`로 공급자를 추가하거나 셸에서 `spirit model add`로 추가할 수 있습니다. [퀵스타트](../quickstart.mdx)를 참조하세요.
