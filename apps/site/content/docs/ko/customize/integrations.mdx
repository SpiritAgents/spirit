---
title: 통합
description: GitHub 기기 로그인. 토큰은 키링에 저장됩니다.
---

**설정 → 통합**은 OAuth 기기 흐름으로 GitHub을 연결합니다. 브라우저에서 승인하면 {{product.name|mdx}}은 시스템 키링의 `{{product.name}}` 서비스 아래에 토큰을 저장합니다.

전체 패널은 Electron 앱에서 사용할 수 있습니다. 다른 셸에서는 제한된 공지가 표시될 수 있습니다.

GitHub은 [Automations](./automations.mdx)이 pull request나 이슈에서 트리거하기 전에 필요합니다. GitHub 연결을 해제하면 해당 트리거 경로가 제거됩니다. 기존 시간 자동화는 계속 실행됩니다.
