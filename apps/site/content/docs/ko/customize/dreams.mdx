<Callout type="warn" title="베타">
  Dreams는 아직 실험 단계입니다. 영구 프로젝트 위키로 취급하지 마십시오. 그런 것은
  [Rules](./rules.mdx)나 저장소에 넣어야 합니다.
</Callout>

Dreams는 **현재 워크스페이스와 Git 브랜치**에 범위가 지정된 짧은 기억입니다: 최근에 무엇이 움직였는지, 왜 중요한지, 아직 해결되지 않은 것이 무엇인지. 레코드는 `{spiritDataDir}/dreams/` 아래에 있으며 **5일** 후에 만료됩니다.

대화 에이전트는 시스템 메시지에서 요약 카탈로그(id, 제목, 요약, 태그)를 얻습니다. 전체 세부 정보는 사전에 로드되지 않습니다. 필요할 때 도구로 가져오십시오.

| 도구         | 역할                                  |
| ------------ | ------------------------------------- |
| `dream_list` | 현재 범위에서 만료되지 않은 요약 목록 |
| `dream_read` | ID로 전체 레코드 하나 읽기            |

`dream_record`, `dream_update`, `dream_delete`는 대화 에이전트가 아닌 백그라운드 수집기에 속합니다. 수집기는 세션을 스캔하고 오래된 항목을 생성, 업데이트 또는 삭제할지 결정합니다. 기존 dream을 복제하는 것보다 업데이트하는 것을 선호합니다.

Desktop의 **Settings → Dreams**에서 수집을 켜거나 끌 수 있습니다. 백그라운드 수집은 **Settings → Tab**과 동일한 슬롯인 보조 언어 모델을 사용합니다. CLI와 ACP는 아직 Dreams를 연결하지 않습니다.
