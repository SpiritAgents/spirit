규칙은 에이전트가 항상 고려하는 Markdown입니다. 세 가지 슬롯이 있습니다:

| 범위                       | 경로                          |
| -------------------------- | ----------------------------- |
| 워크스페이스 에이전트 파일 | `{workspace}/AGENTS.md`       |
| 워크스페이스 Spirit 규칙   | `{workspace}/.spirit/rule.md` |
| 사용자 규칙                | `{spiritDataDir}/rule.md`     |

`AGENTS.md`에 프로젝트 규칙을 작성하여 저장소를 여는 모든 사람이 볼 수 있게 하세요. `.spirit/rule.md`는 일반 에이전트 파일에 포함하고 싶지 않은 Spirit 특정 메모에 사용하세요. 사용자 규칙은 워크스페이스 간에 따라다니는 기본 설정에 사용하세요.

**설정 → 규칙**에서 슬롯을 관리하세요. 내장 스킬인 `create-rule`이 규칙 파일 초안을 작성해 줄 수 있습니다. [확장 프로그램](../develop/extensions.mdx)에 번들된 rule은 해당 확장이 켜져 있을 때만 적용되며 이 설정 목록에는 나타나지 않습니다.
