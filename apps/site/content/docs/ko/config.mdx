공유 사용자 데이터 경로는 빌드 quality에 따라 결정되며 OS의 애플리케이션 데이터 디렉터리를 사용하지 않습니다.

## 데이터 디렉터리

`SPIRIT_DATA_DIR`로 재정의할 수 있습니다. 서버는 `SPIRIT_SERVER_DATA_DIR`도 사용할 수 있습니다(전자보다 우선).

| 빌드 | macOS / Linux | Windows |
| --- | --- | --- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev | `~/{{product.dev.userDataFolderName}}` | `%USERPROFILE%\{{product.dev.userDataFolderName}}` |

Breaking Change: 이전 플랫폼 디렉터리를 자동으로 읽거나 마이그레이션하지 않습니다. 데이터 디렉터리를 명시적으로 지정하는 기능은 유지됩니다. Electron 캐시, 브라우저 저장소, 창 상태는 플랫폼 전용 애플리케이션 디렉터리에 남습니다.

일반적인 파일:

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

CLI 바이너리는 SPIRIT_HOME을 사용합니다. Unix에서는 Stable 설치와 공유 데이터가 같은 상위 디렉터리를 사용할 수 있지만 bin/과 cli/는 설치 파일입니다. 설치 설정은 공유 데이터 디렉터리를 결정하지 않습니다.

## config.json v2

`schemaVersion`은 `2`여야 합니다. 버전 1은 거부됩니다 — 이전 파일을 삭제하고 [프로바이더를 다시 연결](./providers.mdx)하세요.

핵심 필드:

- `providerGroups` — 연결된 하우스, API 베이스, 전송, 모델
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `lightweightChatModel`

키(Key)는 이 파일에 **없습니다**. 키는 [키링](./security.mdx)에 있습니다.

## 작업공간 `{{product.workspaceDataFolderName}}/`

| 경로                 | 역할                                    |
| -------------------- | --------------------------------------- |
| `{{product.workspaceDataFolderName}}/rule.md`    | 작업공간 [규칙](./customize/rules.mdx)  |
| `{{product.workspaceDataFolderName}}/skills/`    | 작업공간 [스킬](./customize/skills.mdx) |
| `{{product.workspaceDataFolderName}}/mcp.json`   | 작업공간 [MCP](./customize/mcp.mdx)     |
| `{{product.workspaceDataFolderName}}/hooks.json` | 작업공간 [훅](./customize/hooks.mdx)    |

또한 사용됨: `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## 환경 변수

| 변수                                                              | 역할                             |
| ----------------------------------------------------------------- | -------------------------------- |
| `SPIRIT_DATA_DIR`                                                 | 데이터 디렉터리                  |
| `SPIRIT_SERVER_DATA_DIR`                                          | 서버 데이터 디렉터리(우선)       |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                 |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | CLI 설치 프로그램                |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | [CLI](./cli.mdx) 프로세스 재정의 |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | 데스크톱 웹 호스트               |
| `SPIRIT_TERMINAL_SHELL`                                           | 데스크톱 PTY 셸                  |
