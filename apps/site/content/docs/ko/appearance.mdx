title: 모양
description: 테마, 글꼴 및 10가지 UI 언어.
---

**설정 → 모양**을 엽니다.

## 테마

`system`, `light` 또는 `dark`. `spirit-desktop-theme`로 저장됩니다.

## 글꼴

기본값은 시스템 글꼴입니다. 사용자 지정 글꼴로 전환할 수 있습니다.

## UI 언어

Desktop / CLI UI에는 **10가지** 언어가 있습니다. 기본값은 중국어 간체입니다.

| 코드    | 언어              |
| ------- | ----------------- |
| `zh-CN` | 简体中文 (기본값) |
| `en`    | 영어              |
| `zh-TW` | 중국어 번체       |
| `ja`    | 일본어            |
| `ko`    | 한국어            |
| `de`    | 독일어            |
| `fr`    | 프랑스어          |
| `es`    | 스페인어          |
| `pt-BR` | 브라질 포르투갈어 |
| `ru`    | 러시아어          |

기타 모양 토글(마이카/흐림, 포인터)은 같은 설정 페이지에 있습니다.
