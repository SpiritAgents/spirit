ACP(Agent Client Protocol)는 `spirit-acp`(`@spiritagent/acp-server`)로 구현됩니다. stdio ndJSON을 사용하며, Desktop 및 CLI와 동일한 데이터 디렉터리와 키링을 공유하고, `--setup`을 실행하여 공급자를 연결할 수 있습니다.

**공개 다운로드 페이지에는 아직 ACP가 나열되지 않습니다.** {{product.name|mdx}}는 아직 ACP 레지스트리에 등록을 준비 중입니다.

## 등록 전 임시 설정

등록될 때까지 `npx`로 설치하고 설정을 완료하세요:

```bash
npx @spiritagent/acp-server --setup
```

또는 ACP 클라이언트(예: Zed)를 stdio 엔트리로 지정합니다:

```json
"agent_servers": {
  "{{product.name}}": {
    "command": "node",
    "args": ["path/to/packages/acp-server/dist/src/stdio-entry.js"]
  }
}
```

**Run in terminal**로 인증하고, `--setup`을 완료한 다음 `authenticate` 및 `session/new`를 실행하세요.

| 변수                   | 역할                                                               |
| ---------------------- | ------------------------------------------------------------------ |
| `SPIRIT_ACP_WORKSPACE` | 작업 공간 루트(기본값: 클라이언트 cwd)                             |
| `SPIRIT_ACP_DATA_DIR`  | 데이터 디렉터리; 그 외에는 `SPIRIT_DATA_DIR`, 그다음 플랫폼 기본값 |
