## config.json이 거부됨

파일은 `schemaVersion: 1`이어야 합니다. 다른 버전은 모두 거부됩니다 — 이전 파일을 삭제하고 [프로바이더 다시 연결](./providers.mdx)하세요. 평문 `apiKey`를 선언하지 않았다면 키는 해당 파일에 없습니다 — 키는 [키링](./security.mdx)에 있습니다.

## CLI 설치됨, 설정 비어 있음

`SPIRIT_HOME` (`~/.spirit`)에 바이너리를 설치했습니다. 세션과 `config.json`은 [데이터 디렉터리](./config.mdx)에 있습니다. `SPIRIT_DATA_DIR`을 재정의했다면 확인하세요.

## `spirit -p` 실패

- 승인 필요 → `-a auto-approval` / `-a bypass-approval` 또는 TUI 사용
- [질문하기](./agent/ask-questions.mdx) 필요 → TUI 사용 또는 프롬프트를 결정적으로 만들기
- 시간 초과 → 헤드리스는 30분 후 중지됩니다

## 모델을 가져오지 못함

해당 하우스의 [프로바이더 페이지](./providers.mdx)를 여세요. 사이트, 플랜 엔드포인트, Azure 리소스, Cloudflare 계정, Bedrock 리전 / IAM, Vertex 프로젝트 / 위치를 확인하세요. TokenHub는 Chat Completions에서 유지됩니다. Bedrock Bearer는 모델을 나열할 수 없습니다.

## 키가 키링에 없음

**설정 → 모델**에서 다시 연결하거나 `spirit model add`를 실행하세요. 마법사는 `config.json` **전에** 키링을 씁니다. 키를 저장소에 붙여넣지 마세요.

## 웹 호스트 페어링 실패

잘못된 코드 → 다시 시도하세요. 다섯 번 실패하면 **설정 → 네트워크**에서 웹 호스트를 다시 시작할 때까지 페어링이 잠깁니다 (`PAIRING_LOCKED`). 호스트는 페어링을 지원해야 합니다. 일반 웹 미리보기는 지원하지 않을 수 있습니다.

## LSP 누락

서버를 직접 설치한 후 (Homebrew / winget으로 clangd, jdtls 수동) **설정 → 에이전트**에서 활성화하세요. [Desktop](./desktop.mdx)을 참조하세요.

## Tab 완성이 비어 있음

**설정 → Tab**을 활성화하고 보조 언어 모델을 할당하세요. [Desktop](./desktop.mdx)을 참조하세요.

## ACP가 다운로드 페이지에 없음

정상입니다. ACP는 구현되었지만 다운로드 열은 여전히 자리 표시자입니다. [ACP](./acp.mdx)를 참조하세요.
