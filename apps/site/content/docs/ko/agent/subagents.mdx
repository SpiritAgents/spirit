---
title: 하위 에이전트
description: 범위가 지정된 작업을 하위 세션에 위임하며, 선택적으로 git 작업 트리에서 수행합니다.
---

에이전트는 `subagent`를 호출하여 하위 세션을 시작할 수 있습니다. 하위 세션은 격리된 작업을 수행하고 최종 결과만 상위 세션에 반환합니다.

## 인수

| 필드               | 필수   | 역할                                                       |
| ------------------ | ------ | ---------------------------------------------------------- |
| `task`             | 예     | 하위 에이전트가 수행할 작업                                |
| `success_criteria` | 아니요 | 하위 에이전트가 작업 완료를 인식하는 방법                  |
| `context_summary`  | 아니요 | 하위 에이전트가 다시 발견하지 않아도 되는 간단한 배경 정보 |
| `files_to_inspect` | 아니요 | 먼저 읽어야 할 경로                                        |
| `expected_output`  | 아니요 | 상위 에이전트가 돌려받기를 원하는 결과의 형태              |
| `worktree`         | 아니요 | `true`인 경우 격리된 git 작업 트리에서 편집합니다          |

하위 에이전트가 파일을 편집하고 다른 하위 에이전트도 동시에 편집할 수 있는 경우 `worktree: true`를 사용하세요. 읽기 전용 작업에서는 생략하세요.

## 제한 사항

작업 트리 내에서 이미 실행 중인 하위 에이전트는 다른 작업 트리를 시작할 수 없습니다. 세션 시작 및 종료 시 후크(`subagentStart` / `subagentEnd`)를 실행할 수 있습니다. Desktop의 하위 에이전트 뷰어나 CLI TUI의 `/subagent`에서 하위 세션을 검사할 수 있습니다.
