각 대화는 세션입니다. 세션은 {{product.name|mdx}} 데이터 디렉터리(`chats/`)에 저장되며 사이드바에서 작업공간별로 그룹화됩니다.

## 되감기

사용자 메시지를 되감아 대화를 해당 시점으로 복원하고, 원하면 프롬프트를 수정한 후 다시 보내세요. 마지막 턴이 잘못된 방향으로 갔을 때, 수정 사항을 덧붙이기보다 재시도하고 싶을 때 사용하세요.

## 포크

어시스턴트 메시지에서 포크하여 대화를 분기하세요. Desktop은 사이드 채팅으로 포크하여 원래 스레드를 유지할 수도 있습니다.

## 워크트리

Composer **작업 위치**는 `local`(열린 작업공간) 또는 `worktree`(격리된 git 워크트리)일 수 있습니다. 하위 에이전트는 동일한 격리를 위해 `worktree: true`를 설정할 수 있습니다.

워크트리 경로는 `{repoRoot}.worktrees/spirit-*` 형태입니다. 이미 워크트리 내에서 실행 중인 하위 에이전트는 그곳에서 다른 워크트리를 시작할 수 없습니다.

워크트리는 그렇지 않으면 충돌할 병렬 편집을 위한 것입니다. 세션의 백업이 아닙니다. 되감기와 포크가 대화 기록을 처리합니다.
