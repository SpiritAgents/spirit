{{product.name|mdx}}에는 네 가지 에이전트 모드가 있습니다. Desktop과 CLI는 Tab으로 순환합니다: **Agent → Plan → Ask → Debug → Agent**.

| 모드      | 기능                                                                                                                                                                                 |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Agent** | 기본 모드. 읽기, 편집, 명령 실행, 검증을 수행합니다.                                                                                                                                 |
| **Plan**  | 계획만 수행합니다. [ask_questions](./ask-questions.mdx)로 명확히 하고, `create_plan`으로 계획을 작성한 후 구현을 시작하거나 Agent 모드로 전환할 것을 요청합니다.                     |
| **Ask**   | 읽기 전용. 설명하고 검색합니다. 파일 편집, 셸, 패치, 미디어 생성은 사용할 수 없습니다. 코드를 변경하려면 Agent 모드로 전환하세요.                                                    |
| **Debug** | 버그를 조사합니다: 가설을 순위화하고 `{{product.workspaceDataFolderName}}/logs/` 아래에 NDJSON 로그를 삽입하며(`#region agent log`로 감쌈), 문제가 해결되었는지 또는 계속 재현되는지 사용자의 응답을 기다립니다. |

변경 사항이 크거나 목표가 모호할 때는 Plan을 사용하세요. 저장소를 이해하고 싶을 때만 Ask를 사용하세요. 실패를 재현할 수 있고 체계적인 접근이 필요할 때 Debug를 사용하세요. 일반적인 편집에는 Agent를 유지하세요.

편집기의 Tab 완성은 다른 기능입니다. 이 순환에 포함되지 않으며 설정 → Tab에서 찾을 수 있습니다.
