루프는 세션 전환입니다. 켜져 있으면 일반적인 어시스턴트 메시지가 턴을 **종료하지 않습니다**. 에이전트는 작업이 완료될 때까지 도구를 계속 사용한 다음 `finish_task`를 호출해야 합니다.

## 켜기

Desktop에서는 컴포저에서 루프를 활성화합니다(`/loop` 칩). CLI TUI에서는 `/loop`를 실행합니다.

`finish_task`는 루프가 켜져 있을 때만 노출됩니다. 루프가 꺼져 있는데 모델이 여전히 호출하면 {{product.name|mdx}}은 알 수 없는 도구로 호출을 거부합니다.

## 사용 시기

구현, 테스트, 수정, 반복과 같이 감독하고 싶지 않은 다단계 작업에는 루프를 사용하세요. 단일 질문이나 단일 파일 편집에는 끄세요.

루프는 [승인](./approvals.mdx)을 변경하지 않습니다. 기본 승인은 여전히 편집 및 셸에서 일시 중지됩니다.
