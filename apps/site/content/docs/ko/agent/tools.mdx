title: 도구
description: 에이전트가 호출할 수 있는 도구입니다. 일부 도구는 모델, 슬롯 또는 모드가 적격할 때만 표시됩니다.
---

이 도구들은 사용자가 연 작업 공간에서 작동합니다. 질문 모드는 읽기 및 검색만 가능하며, 생성, 편집, 삭제, 패치 적용, `shell` 실행, 이미지 또는 비디오 생성은 할 수 없습니다.

| 도구              | 역할                                                                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `read_file`       | 파일 읽기 또는 이미지 및 비디오 읽기                                                                                                  |
| `create_file`     | 파일 생성                                                                                                                             |
| `edit_file`       | 기존 파일 편집                                                                                                                        |
| `delete_file`     | 파일 삭제                                                                                                                             |
| `apply_patch`     | 모델과 전송이 적격할 때 노출됩니다(예: OpenAI 제공 GPT 모델). 해당 경로에서 `create_file` / `edit_file` / `delete_file`을 대체합니다. |
| `glob`            | glob으로 경로 찾기(`.gitignore` 존중)                                                                                                 |
| `grep`            | 파일 내용 검색(`.gitignore` 존중)                                                                                                     |
| `ls`              | 디렉토리 하나를 나열하며, 재귀적이지 않습니다. 경로는 절대 경로여야 합니다.                                                           |
| `shell`           | `reason` 및 `command`로 명령 실행. 질문 모드는 호출할 수 없습니다.                                                                    |
| `web_fetch`       | `http` 또는 `https` URL을 가져와 Markdown으로 반환합니다. 호스트 도구이며 공급자 검색이 아닙니다.                                     |
| `generate_image`  | **설정 → 모델**에서 이미지 모델을 지정한 후 노출됩니다. 하나의 이미지를 생성합니다. 질문 모드는 호출할 수 없습니다.                   |
| `generate_video`  | **설정 → 모델**에서 비디오 모델을 지정한 후 노출됩니다. 짧은 비디오를 생성합니다. 질문 모드는 호출할 수 없습니다.                     |
| `get_diagnostics` | 언어 서버가 준비되면 노출됩니다. 경로를 전달하고 오류 및 경고를 반환합니다. 질문 모드에서 사용할 수 있습니다.                         |
| `ask_questions`   | 구조화된 질문; 턴은 사용자가 답변할 때까지 기다립니다. [질문하기](./ask-questions.mdx)를 참조하세요.                                  |
| `subagent`        | 범위가 지정된 작업을 하위 세션에 위임합니다. [하위 에이전트](./subagents.mdx)를 참조하세요.                                           |
| `create_plan`     | 계획 모드 전용. `plans/{name}.md`를 작성합니다. [모드](./modes.mdx)를 참조하세요.                                                     |
| `todo_list`       | 현재 세션의 할 일 목록 표시                                                                                                           |
| `todo_write`      | 현재 세션의 전체 할 일 목록을 대체                                                                                                    |
| `finish_task`     | [루프](./loop.mdx)가 켜져 있을 때만 노출됩니다. 현재 작업을 완료로 표시합니다.                                                        |
| `dream_list`      | [Dreams](../customize/dreams.mdx)를 데스크톱에서 사용할 수 있을 때, 현재 작업 공간 및 분기에 대한 만료되지 않은 요약을 나열합니다.    |
| `dream_read`      | ID로 전체 Dream 하나를 읽습니다. 쓰기 도구는 대화가 아닌 백그라운드 수집기에 속합니다.                                                |

편집 및 삭제는 기본 수준에서 [승인](./approvals.mdx)을 기다립니다. `shell`도 마찬가지입니다.

구성된 [MCP](../customize/mcp.mdx) 서버 및 확장은 같은 목록에 더 많은 도구를 추가합니다.

## 프로바이더 도구 [#provider-tools]

프로바이더는 자체 도구(웹 검색, 코드 인터프리터 등)를 노출할 수 있습니다. 어떤 도구가 존재하는지는 연결된 프로바이더가 [config.json](../config.mdx)에 선언한 내용(연결 마법사가 작성)에 따라 결정되며, {{product.name|mdx}}의 내장 도구가 아닙니다. 도구를 선언하지 않은 프로바이더는 아무것도 노출하지 않습니다.

선언에 따라 호출은 업스트림 요청 내에서 실행되거나, {{product.name|mdx}}이 선언대로 HTTP로 실행하여 도구 결과로 다시 기록합니다. 두 형태 모두 MCP 도구 호출처럼 렌더링되며, 런타임은 선언된 매개변수를 임의로 변경하지 않습니다.

**설정 → 에이전트**의 **프로바이더 도구** 토글(`agents.providerTools.enabled`, 기본값 켜짐)이 이 모든 것을 한 번에 제어합니다. 프로바이더별 선언된 도구 목록은 [프로바이더](../providers.mdx)를 참조하세요.
