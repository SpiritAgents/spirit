共享用户数据按构建 quality 选择目录，不再使用操作系统的应用数据目录。

## 数据目录

用 `SPIRIT_DATA_DIR` 覆盖。Server 还可以用 `SPIRIT_SERVER_DATA_DIR`（优先于前者）。

| 构建   | macOS / Linux                             | Windows                                               |
| ------ | ----------------------------------------- | ----------------------------------------------------- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev    | `~/{{product.dev.userDataFolderName}}`    | `%USERPROFILE%\{{product.dev.userDataFolderName}}`    |

Breaking Change：不会自动读取或迁移旧平台数据目录；仍支持显式数据目录覆盖。Electron 缓存、浏览器存储和窗口状态继续保留在平台私有应用目录中。

常见文件：

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

CLI 二进制使用 SPIRIT_HOME。在 Unix 上，Stable 安装与共享数据可以共用父目录；bin/ 和 cli/ 仍属于安装文件。安装设置不决定共享数据目录。

## config.json v2

`schemaVersion` 必须是 `2`。版本 1 会被拒绝——删掉旧文件，再[重连提供商](./providers.mdx)。

核心字段：

- `providerGroups` — 已接的提供商、API Base、传输、模型
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `secondaryLanguageModel`
- `permission` — 权限允许列表规则

Key **不在**这个文件里。它们在[钥匙串](./security.mdx)。

### permission

`permission` 在会话[审批档位](./agent/approvals.mdx)之上，精确规定单个 shell 命令和文件路径能做什么。键是工具名（`shell`、`read_file`）；值把通配符模式映射为 `allow`、`ask` 或 `deny`。

```json
{
  "permission": {
    "shell": {
      "git *": "allow",
      "rm -rf *": "deny"
    }
  }
}
```

`deny` 是绝对的——任何审批档位、hook 或会话记忆都无法覆盖它。模式语法、路径语义和完整动作列表见[审批](./agent/approvals.mdx)。不实际运行即可验证规则：`spirit permission check --shell "git status"`。

旧的 `tool-permissions.json`（由「始终信任」按钮写入）已废弃：代码不再读取或写入它，也没有自动迁移。残留文件已失效——请手动删除。

## 工作区 `{{product.workspaceDataFolderName}}/`

| 路径                                             | 作用                                    |
| ------------------------------------------------ | --------------------------------------- |
| `{{product.workspaceDataFolderName}}/rule.md`    | 工作区 [rule](./customize/rules.mdx)    |
| `{{product.workspaceDataFolderName}}/skills/`    | 工作区 [技能](./customize/skills.mdx) |
| `{{product.workspaceDataFolderName}}/mcp.json`   | 工作区 [MCP](./customize/mcp.mdx)       |
| `{{product.workspaceDataFolderName}}/hooks.json` | 工作区 [hooks](./customize/hooks.mdx)   |

另外还会用：`{workspace}/AGENTS.md`、`{workspace}/.agents/skills/`、`{workspace}/plans/`。

## 环境变量

| 变量                                                              | 作用                      |
| ----------------------------------------------------------------- | ------------------------- |
| `SPIRIT_DATA_DIR`                                                 | 数据目录                  |
| `SPIRIT_SERVER_DATA_DIR`                                          | Server 数据目录（优先）   |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)          |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | CLI 安装脚本              |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | [CLI](./cli.mdx) 进程覆盖 |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | Desktop Web Host          |
| `SPIRIT_TERMINAL_SHELL`                                           | Desktop PTY shell         |
