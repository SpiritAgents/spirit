## 模型提供商

{{product.name|mdx}} 不直接提供模型服务。你可以接入 OpenAI、Anthropic、SpaceXAI、网关或区域提供商。无论接哪一家，都走同一套 Harness：工具、审批、会话和工作区行为保持一致。

密钥写入系统钥匙串，服务名为 `{{product.name}}`，不会写入 `config.json`。

## 一个 Agent，两个宿主

Desktop 与 CLI 共用本机守护进程。会话、模型、审批和凭证在同一数据目录，你可以在应用里开工，再在终端里接着做。

## 从这里开始

1. [安装 Desktop 或 CLI](./quickstart.mdx)
2. 打开一个工作区
3. 接上第一家提供商
4. 让 Agent 读仓库、做一次小改，并走审批

完整路径见 [上手](./quickstart.mdx)。
