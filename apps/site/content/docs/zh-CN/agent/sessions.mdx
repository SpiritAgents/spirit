每一段对话是一个会话。会话存在 {{product.name|mdx}} 数据目录的 `chats/` 下，侧栏按工作区分组。

## Rewind

把某条用户消息 rewind 回去，会话会回到那一点；你可以按需修改提示词再发送。当上一轮走偏、你宁愿重试而不是叠加一句纠正时，就使用它。

## Fork

从某条助手消息 fork，即可让对话分出一条分支。Desktop 也可以 fork 到侧边会话，这样原线程保持不动。

## Worktree

输入框的**工作地点**可以是 `local`（你打开的工作区）或 `worktree`（隔离的 git worktree）。子智能体也可以设 `worktree: true` 做同样的隔离。

Worktree 路径形如 `{repoRoot}.worktrees/spirit-*`。已经在 worktree 里跑的子智能体不能再从那里开一层 worktree。

Worktree 用于那些否则会互相冲突的并行编辑。它不是会话的备份——对话历史由 rewind 和 fork 负责。
