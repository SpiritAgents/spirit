像向能够阅读仓库、并会等待审批的同事交代任务那样与 Agent 对话。

## 说清楚

指明文件、预期结果，以及不要改动的部分。明确的提示会得到一小段可审查的 diff。含糊的提示会把一轮消耗在探查上。

```txt
阅读 src/auth/session.ts，修复过期 token 的刷新路径。
不要修改登录表单。在现有 session 测试旁补一个针对性测试。
```

## 附上上下文

在 Desktop 上，如果任务针对某个具体位置，请附上打开的文件、选区或 Browser 中选中的元素。Agent 仍需读取文件才能看到当前内容——附件是指针，不能代替[工具](./tools.mdx)。

## 先选择模式

- **Agent** — 你已经知道要改什么
- **Plan** — 你希望先有书面计划和[提问](./ask-questions.mdx)，再进行任何编辑
- **Ask** — 你只需要解释
- **Debug** — 你能复现问题，并希望看到日志

见[模式](./modes.mdx)。

## 让审批发挥作用

在**默认**审批下，Agent 会在编辑或运行命令前停下。阅读 diff，然后批准或拒绝。在信任这条回路之前，不要开启绕过。见[审批](./approvals.mdx)。

编辑器内联补全（Tab）不属于本次对话。在 **设置 → Tab** 中配置。
