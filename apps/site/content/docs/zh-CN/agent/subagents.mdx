---
title: 子智能体
description: 把限定任务交给子会话，可选隔离到 git worktree。
---

Agent 可以调用 `subagent` 开一个子会话。子会话做一件隔离的事，只把最终结果交回父会话。

## 参数

| 字段               | 必填 | 作用                                    |
| ------------------ | ---- | --------------------------------------- |
| `task`             | 是   | 子智能体要做什么                        |
| `success_criteria` | 否   | 怎样算做完                              |
| `context_summary`  | 否   | 子智能体不必自己再挖的背景              |
| `files_to_inspect` | 否   | 先读哪些路径                            |
| `expected_output`  | 否   | 父会话希望收回的结果形态                |
| `worktree`         | 否   | `true` 时在隔离的 git worktree 里改文件 |

子智能体会改文件、且可能和其他子智能体同时改时，设 `worktree: true`。只读任务不要开。

## 限制

已经在 worktree 里跑的子智能体不能再开一层 worktree。会话开始和结束可以跑 hook（`subagentStart` / `subagentEnd`）。Desktop 的子智能体查看器或 CLI TUI 的 `/subagent` 可以检查子会话。
