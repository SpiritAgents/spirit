CLI 是终端宿主，带 TUI 和非交互 `-p` 模式。它与 [Desktop](./desktop.mdx) 连同一套本机守护进程。

## 安装脚本

macOS 与 Linux：

```bash
curl -fsSL {{product.websiteOrigin}}/install | bash
```

Windows（PowerShell）：

```powershell
irm {{product.websiteOrigin}}/install.ps1 | iex
```

脚本从 `{{product.downloadOrigin|host}}` 下载构建，用 GitHub 同 Release 的 `SHA256SUMS.txt` 校验 SHA-256（不一致则中止），再解包并把 `spirit` 加进 `PATH`。

新开一个终端，然后：

```bash
spirit --version
```

## 装到哪里

CLI 二进制使用 SPIRIT_HOME。在 Unix 上，Stable 安装与共享数据可以共用父目录；bin/ 和 cli/ 仍属于安装文件。安装设置不决定共享数据目录。

|                        | 默认                                                                                                         | 覆盖              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------- |
| CLI 二进制             | Unix：`~/.spirit` · Windows：`%LOCALAPPDATA%\Spirit`                                                         | `SPIRIT_HOME`     |
| 会话、配置、钥匙串指针 | Stable: `~/{{product.stable.userDataFolderName}}` · Dev: `~/{{product.dev.userDataFolderName}}` · Windows: `%USERPROFILE%\{{product.stable.userDataFolderName}}` / `%USERPROFILE%\{{product.dev.userDataFolderName}}` | `SPIRIT_DATA_DIR` |

在 Unix 上，脚本把 `$SPIRIT_HOME/bin/spirit` 链到 `$SPIRIT_HOME/cli/current/bin/spirit`，并在 `~/.profile`、`~/.bashrc`、`~/.zshrc` 追加 `export PATH="$SPIRIT_HOME/bin:$PATH"`（标记 `# spirit cli`）。

## 钉版本或换镜像

| 变量                   | 默认                                   | 作用                |
| ---------------------- | -------------------------------------- | ------------------- |
| `SPIRIT_HOME`          | `~/.spirit` 或 `%LOCALAPPDATA%\Spirit` | CLI 二进制安装根    |
| `SPIRIT_VERSION`       | `latest`                               | 下载 URL 里的版本段 |
| `SPIRIT_DOWNLOAD_HOST` | `{{product.downloadOrigin|host}}`                  | CDN 主机            |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL {{product.websiteOrigin}}/install | bash
```

也可以从[下载页](/zh-CN/download)或 [GitHub Releases](https://github.com/SpiritAgents/spirit/releases/latest) 自行下载 CLI 压缩包再解压。

## 第一次运行

```bash
cd /path/to/your/project
spirit
```

这会打开 TUI。用 `/model add` 接提供商，或在 shell 里运行 `spirit model add`。见[上手](../quickstart.mdx)。
