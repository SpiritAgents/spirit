---
title: 安装 Desktop
description: 在 macOS、Windows 或 Linux 上下载 Spirit 桌面版。
---

Desktop 是图形宿主：对话、工作区文件、Git、设置、扩展和自动化。它与 [CLI](./cli.mdx) 共用本机守护进程。

## 下载

到[下载页](/zh-CN/download)获取安装包。页面会按你的系统和架构从 `download.spirit.dev` 取对应构建。

| 平台    | 文件           | 架构             |
| ------- | -------------- | ---------------- |
| macOS   | `.dmg`         | x64、arm64       |
| Windows | `.exe`（NSIS） | x64、arm64、ia32 |
| Linux   | `.AppImage`    | x64、arm64       |

也可以从 GitHub [最新 Release](https://github.com/SpiritAgents/spirit/releases/latest) 下载。Linux Release 除 AppImage 外可能还有 `.deb`。

Desktop 没有官方 Homebrew、winget 或 apt 包。

## 装完之后

1. 打开 Spirit。
2. [打开一个工作区](../quickstart.mdx#2-打开工作区)。
3. 在 **设置 → 模型** 接上提供商。Key 会写入系统钥匙串。

macOS 上若 Gatekeeper 拦住首次启动，在 Finder 里 Control-点击应用 → 打开。

Linux 上先给 AppImage 加上可执行权限（`chmod +x Spirit-linux-*.AppImage`）再运行。

## 更新

下载页和 CDN 的 `latest` 路径始终指向当前 Desktop 构建。需要钉版本时，用 GitHub Releases 里的带版本资源。
