title: 外观
description: 主题、字体和十种界面语言。
---

打开 **设置 → 外观**。

## 主题

`system`、`light` 或 `dark`。存在 `spirit-desktop-theme`。

## 字体

默认使用系统字体。可以改成自定义字体族。

## 界面语言

Desktop / CLI 界面有 **十种** 语言。默认是简体中文。

| 代码    | 语言                |
| ------- | ------------------- |
| `zh-CN` | 简体中文（默认）    |
| `en`    | English             |
| `zh-TW` | 繁體中文            |
| `ja`    | 日本語              |
| `ko`    | 한국어              |
| `de`    | Deutsch             |
| `fr`    | Français            |
| `es`    | Español             |
| `pt-BR` | Português do Brasil |
| `ru`    | Русский             |

其他外观开关（云母 / 模糊、指针）也在同一设置页。
