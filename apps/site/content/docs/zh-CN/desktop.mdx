## 工作区面板

| 标签    | 作用                                     |
| ------- | ---------------------------------------- |
| Files   | 文件树、Monaco、Markdown 预览、`plans/`  |
| Git     | 变更、历史、commit / push / merge chip   |
| Browser | 嵌入浏览器 + 元素选取（**仅 Electron**） |
| Shell   | 嵌入 PTY（**仅 Electron**）              |

### Shell

Desktop（仅 Electron）有 **Shell** 标签和嵌入式 PTY。那是给你用的。Agent 仍然走 [`shell`](./agent/tools.mdx) 和审批，不会往你的 PTY 里打字。

CLI 没有嵌入式 PTY 面板。命令仍通过共用守护进程上的同一个 `shell` 工具执行。

需要指定 Desktop PTY 的 shell 时，用 `SPIRIT_TERMINAL_SHELL`。

### Git

**Git** 标签显示变更和历史。输入框上的 chip 可以发起 **commit**、**push** 或 **merge**。这是宿主 UI，不是 Skill 包。

Chip 会注入固定提示。随后 Agent 用[工作区和 `shell` 工具](./agent/tools.mdx)。

### LSP

到 **设置 → 智能体** 打开语言服务器，缺哪个提供商就装哪个。装好后 Agent 可用 [`get_diagnostics`](./agent/tools.mdx)。

| Id              | 语言   | 安装方式                          |
| --------------- | ------ | --------------------------------- |
| `pyright`       | Python | npm（`pyright`）                  |
| `gopls`         | Go     | Go 工具链                         |
| `rust-analyzer` | Rust   | rustup                            |
| `clangd`        | C、C++ | 平台包（例如 Homebrew 或 winget） |
| `jdtls`         | Java   | 手动                              |
| `omnisharp`     | C#     | .NET                              |

clangd 和 jdtls 不随包装。自己装好，再回到 **设置 → 智能体**。

### Tab

Tab 是 Monaco 内联补全，按一次 Tab 接受幽灵文字。到 **设置 → Tab** 打开代码补全（`codeCompletionEnabled`），并在 **设置 → 模型** 指定轻量对话模型。这个槽位也给其他轻量后台任务用。

没有建议时，检查轻量对话模型是否已连接，以及开关是否打开。这不是 Agent 对话。

## Web Host 配对

Desktop 可以在本机给 Web 客户端提供服务。

- 默认监听：`127.0.0.1:7788`
- 设置 → **网络** → Web 远程访问
- 首次访问要输入该设置页上的 **6 位配对码**
- 失败 5 次会锁定，直到你重启 Web Host
- Token 存在浏览器的 `spirit-web-host-token`

Agent 仍在共用守护进程里跑。Web 客户端拿到的是已鉴权快照，不是第二套 Agent。

**把 `0.0.0.0` 绑出去做远程局域网访问，不是已开放的产品路径。** 守护进程和 Web Host 默认留在 loopback。网络设置里的局域网 IPv4 是给你控制的那台机器，不是公网服务器。

开发覆盖：`SPIRIT_DESKTOP_WEB_HOST=1`、`SPIRIT_WEB_HOST`、`SPIRIT_WEB_PORT`。
