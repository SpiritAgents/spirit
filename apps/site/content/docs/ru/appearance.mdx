---
title: Внешний вид
description: Тема, шрифты и десять языков интерфейса.
---

Откройте **Настройки → Внешний вид**.

## Тема

`system`, `light` или `dark`. Сохраняется как `spirit-desktop-theme`.

## Шрифт

По умолчанию используется системный шрифт. Вы можете переключиться на настраиваемое семейство.

## Языки интерфейса

Интерфейс Desktop / CLI имеет **десять** языков. По умолчанию используется упрощённый китайский.

| Код     | Язык                     |
| ------- | ------------------------ |
| `zh-CN` | 简体中文 (по умолчанию)  |
| `en`    | Английский               |
| `zh-TW` | Традиционный китайский   |
| `ja`    | Японский                 |
| `ko`    | Корейский                |
| `de`    | Немецкий                 |
| `fr`    | Французский              |
| `es`    | Испанский                |
| `pt-BR` | Португальский (Бразилия) |
| `ru`    | Русский                  |

Другие переключатели внешнего вида (mica / blur, указатель) остаются на той же странице настроек.
