title: Loop

Loop — это переключатель сеанса. Когда он включён, обычное сообщение ассистента **не** завершает ход. Ожидается, что агент продолжит использовать инструменты, пока задача не будет выполнена, а затем вызовет `finish_task`.

## Включение

В Desktop включите Loop в композере (чип `/loop`). В TUI CLI выполните `/loop`.

`finish_task` доступен только пока Loop включён. Если Loop выключен, а модель всё равно вызывает его, {{product.name|mdx}} отклоняет вызов как неизвестный инструмент.

## Когда использовать

Используйте Loop для многошаговой работы, за которой не нужно постоянно следить: реализуйте, тестируйте, исправляйте, повторяйте. Оставьте его выключенным для одного вопроса или правки одного файла.

Loop не меняет [утверждение](./approvals.mdx). Стандартное утверждение по-прежнему приостанавливается при правках и в shell.
