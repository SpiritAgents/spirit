---
title: Суб-агенты
description: Делегируйте ограниченную задачу дочерней сессии, опционально в git worktree.
---

Агент может вызвать `subagent` для запуска дочерней сессии. Дочерний агент работает над изолированной задачей и возвращает родительскому агенту только свой итоговый результат.

## Аргументы

| Поле               | Обязательно | Роль                                                                       |
| ------------------ | ----------- | -------------------------------------------------------------------------- |
| `task`             | да          | Что должен сделать дочерний агент                                          |
| `success_criteria` | нет         | Как дочерний агент узнает, что задача выполнена                            |
| `context_summary`  | нет         | Краткая предыстория, которую дочернему агенту не придется заново открывать |
| `files_to_inspect` | нет         | Пути для чтения в первую очередь                                           |
| `expected_output`  | нет         | Форма результата, которую родительский агент хочет получить обратно        |
| `worktree`         | нет         | `true` для редактирования в изолированном git worktree                     |

Используйте `worktree: true`, когда дочерний агент будет редактировать файлы, а другие дочерние агенты могут редактировать одновременно. Опустите этот параметр для работы только на чтение.

## Ограничения

Дочерний агент, уже запущенный внутри worktree, не может запустить другой worktree. Начало и конец сессии могут запускать хуки (`subagentStart` / `subagentEnd`). Вы можете просматривать дочерние сессии в просмотрщике суб-агентов на Desktop или через `/subagent` в CLI TUI.
