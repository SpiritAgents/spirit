---
title: Инструменты
description: Инструменты, которые может вызывать агент. Некоторые отображаются только при определенных условиях модели, слота или режима.
---

Эти инструменты работают с открытым вами рабочим пространством. Режим «Спросить» может читать и искать; он не может создавать, редактировать, удалять, применять патчи, запускать `shell` или генерировать изображения и видео.

| Инструмент        | Роль                                                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `read_file`       | Читать файл, а также изображения и видео                                                                                                         |
| `create_file`     | Создать файл                                                                                                                                     |
| `edit_file`       | Редактировать существующий файл                                                                                                                  |
| `delete_file`     | Удалить файл                                                                                                                                     |
| `apply_patch`     | Доступен, когда модель и транспорт подходят (например, GPT-модель от OpenAI); заменяет `create_file` / `edit_file` / `delete_file` в этом случае |
| `glob`            | Поиск путей по glob (учитывает `.gitignore`)                                                                                                     |
| `grep`            | Поиск по содержимому файлов (учитывает `.gitignore`)                                                                                             |
| `ls`              | Список файлов в одной директории, не рекурсивно. Путь должен быть абсолютным                                                                     |
| `shell`           | Выполнить команду с `reason` и `command`. Режим «Спросить» не может его вызывать                                                                 |
| `web_fetch`       | Получить URL `http` или `https` и вернуть Markdown. Системный инструмент, а не поиск провайдера                                                  |
| `generate_image`  | Доступен после назначения модели изображений в **Настройки → Модели**. Генерирует одно изображение. Режим «Спросить» не может его вызывать       |
| `generate_video`  | Доступен после назначения модели видео в **Настройки → Модели**. Генерирует короткое видео. Режим «Спросить» не может его вызывать               |
| `get_diagnostics` | Доступен, когда языковой сервер готов. Передайте пути; возвращает ошибки и предупреждения. Режим «Спросить» может его использовать               |
| `ask_questions`   | Структурированные вопросы; ход ожидает вашего ответа. См. [Задать вопросы](./ask-questions.mdx)                                                  |
| `subagent`        | Делегировать ограниченную задачу дочернему сеансу. См. [Суб агенты](./subagents.mdx)                                                             |
| `create_plan`     | Только режим планирования. Записывает `plans/{name}.md`. См. [Режимы](./modes.mdx)                                                               |
| `todo_list`       | Список задач для текущего сеанса                                                                                                                 |
| `todo_write`      | Заменить весь список задач для текущего сеанса                                                                                                   |
| `finish_task`     | Доступен только при включенном [Loop](./loop.mdx). Отмечает текущую задачу завершенной                                                           |
| `dream_list`      | Когда [Dreams](../customize/dreams.mdx) доступен на Desktop, выводит список неистекших сводок для текущего рабочего пространства и ветки         |
| `dream_read`      | Читать одну полную запись Dream по идентификатору. Инструменты записи принадлежат фоновому сборщику, а не разговору                              |

Редактирование и удаление ожидают [одобрения](./approvals.mdx) на уровне по умолчанию. `shell` также ожидает.

Настроенные [MCP](../customize/mcp.mdx) серверы и расширения добавляют больше инструментов в этот же список.

## Инструменты провайдера [#provider-tools]

Провайдеры могут предоставлять собственные инструменты — веб-поиск, интерпретаторы кода и тому подобное. Какие инструменты существуют, определяется декларацией подключённого провайдера в [config.json](../config.mdx) (её записывает мастер подключения), а не встроенным инструментом {{product.name|mdx}}: провайдер, который не объявляет инструменты, не предоставляет ни одного.

В зависимости от декларации вызов либо выполняется внутри запроса к вышестоящей системе, либо {{product.name|mdx}} выполняет его по HTTP согласно декларации и записывает результат как результат инструмента. В обоих случаях он отображается как вызов инструмента MCP, и рантайм никогда сам не изменяет объявленные параметры.

Переключатель **Инструменты провайдера** в **Настройки → Агенты** (`agents.providerTools.enabled`, включён по умолчанию) управляет ими всеми сразу. Список объявленных инструментов по каждому дому — в [Провайдеры](../providers.mdx).
