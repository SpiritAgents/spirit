title: Режимы

  область, разные разрешения.

{{product.name|mdx}} имеет четыре режима агента. Desktop и CLI переключают их с помощью Tab: **Agent → Plan → Ask → Debug → Agent**.

| Режим     | Что он делает                                                                                                                                                                                                         |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Agent** | По умолчанию. Читает, редактирует, запускает команды и проверяет.                                                                                                                                                     |
| **Plan**  | Только планирование. Уточняет с помощью [ask_questions](./ask-questions.mdx), пишет план через `create_plan`, затем просит вас начать реализацию или вернуться в Agent.                                               |
| **Ask**   | Только чтение. Объясняет и ищет. Редактирование файлов, оболочка, патчи и создание медиа недоступны. Переключитесь в Agent, чтобы изменить код.                                                                       |
| **Debug** | Исследует ошибку: ранжирует гипотезы, вставляет NDJSON-логи в `{{product.workspaceDataFolderName}}/logs/` (обёрнутые в `#region agent log`) и ждёт, пока вы скажете, что проблема решена или всё ещё воспроизводится. |

Используйте Plan, когда изменение большое или цель нечёткая. Используйте Ask, когда вы хотите только понять репозиторий. Используйте Debug, когда вы можете воспроизвести сбой и хотите систематический анализ. Оставьте Agent для обычных правок.

Автодополнение по Tab в редакторе — это другая функция. Она находится в Настройки → Tab, а не в этом цикле.
