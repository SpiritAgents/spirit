Рабочий стол — это графический хост. Он использует общий локальный демон с [CLI](./cli.mdx). Установите его из [Установка Desktop](./install/desktop.mdx).

## Панели рабочего пространства

| Вкладка  | Роль                                                       |
| -------- | ---------------------------------------------------------- |
| Файлы    | Дерево, Monaco, предпросмотр Markdown, `plans/`            |
| Git      | Изменения, история, чипы коммита / пуша / слияния          |

### Оболочка

В Desktop (только Electron) есть вкладка **Shell** со встроенным PTY. Эта панель для вас. Агент по-прежнему работает через [`shell`](./agent/tools.mdx) и одобрение; он не печатает в вашем PTY.

В CLI нет встроенной панели PTY. Команды по-прежнему выполняются через тот же инструмент `shell` в общем демоне.

Переопределите оболочку PTY в Desktop с помощью `SPIRIT_TERMINAL_SHELL`, если вам нужен конкретный бинарный файл.

### Git

Вкладка **Git** показывает изменения и историю. Чипы на композере могут запустить **commit**, **push** или **merge**. Это интерфейс хоста, а не пакет Skills.

Эти чипы вставляют фиксированный промпт. Затем агент использует [инструменты рабочего пространства и `shell`](./agent/tools.mdx).

### LSP

Включите языковые серверы в **Настройки → Агенты**, затем установите провайдера, если его нет. Когда сервер готов, агент может вызывать [`get_diagnostics`](./agent/tools.mdx).

| Идентификатор   | Языки  | Как установлен                                  |
| --------------- | ------ | ----------------------------------------------- |
| `pyright`       | Python | npm (`pyright`)                                 |
| `gopls`         | Go     | Инструментарий Go                               |
| `rust-analyzer` | Rust   | rustup                                          |
| `clangd`        | C, C++ | Пакет платформы (например, Homebrew или winget) |
| `jdtls`         | Java   | Вручную                                         |
| `omnisharp`     | C#     | .NET                                            |

clangd и jdtls не входят в комплект. Установите их самостоятельно, затем вернитесь в Настройки → Агенты.

### Вкладка

Tab — это встроенное завершение Monaco. Принимайте призрачный текст одной клавишей Tab. Откройте **Настройки → Tab**, включите завершение кода (`codeCompletionEnabled`) и назначьте легкую чат-модель в **Настройки → Модели**. Этот слот также используется для других фоновых задач.

Если завершение пустое, проверьте, что подключена легковесная чат-модель и что параметр включен. Это не разговор с агентом.

## Расширения и автоматизации

Страница «Расширения» на боковой панели показывает установленные расширения и импортирует ZIP-архивы. Автоматизации имеют собственное представление — [только в Desktop](./customize/automations.mdx).

## Сопряжение с Web Host

Desktop может обслуживать веб-клиент на локальной машине.

- Прослушивание по умолчанию: `127.0.0.1:7788`
- Настройки → **Сеть** → Веб-управление
- При первом посещении запрашивается **6-значный код сопряжения** со страницы настроек
- Пять неудачных попыток блокируют сопряжение до перезапуска Web Host
- Токен хранится в браузере как `spirit-web-host-token`

Агент по-прежнему работает внутри общего демона. Веб-клиент получает аутентифицированный снимок; это не второй агент.

**Привязка `0.0.0.0` для удаленного доступа через LAN не является открытым продуктовым путем.** Демон и Web Host по умолчанию остаются на loopback. Адрес прослушивания LAN IPv4 в Networks предназначен для машины, которую вы контролируете, а не для публичного сервера.

Переопределения для разработки: `SPIRIT_DESKTOP_WEB_HOST=1`, `SPIRIT_WEB_HOST`, `SPIRIT_WEB_PORT`.
