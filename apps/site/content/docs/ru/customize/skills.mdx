Навык — это папка с файлом `SKILL.md`. Spirit обнаруживает навыки в трёх местах:

| Область                | Путь                                         |
| ---------------------- | -------------------------------------------- |
| Пользователь           | `{spiritDataDir}/skills/{name}/SKILL.md`     |
| Рабочая область Spirit | `{workspace}/.spirit/skills/{name}/SKILL.md` |
| Агенты рабочей области | `{workspace}/.agents/skills/{name}/SKILL.md` |

Когда вы упоминаете навык в сообщении, Spirit может прикрепить его полный текст к этому сообщению пользователя. Он не помещает все навыки в системный промпт.

## Frontmatter

`SKILL.md` должен начинаться с Frontmatter. Файл без `name` или `description` не обнаруживается.

| Поле          | Описание                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------- |
| `name`        | Обязательно. Имя навыка; должно совпадать с именем папки. 1–64 символа, только строчные буквы, цифры и дефисы |
| `description` | Обязательно. Короткое описание                                                                                |

## Встроенные навыки

Они поставляются с Spirit (это не файлы в вашем каталоге данных):

- `create-rule` — создание проекта [правила](./rules.mdx)
- `create-skill` — создание проекта [навыка](./skills.mdx)
- `create-hook` — создание проекта [хука](./hooks.mdx)

Управляйте навыками в **Настройки → Навыки**. Чипы Git commit / push / merge — это элементы интерфейса хоста, а не встроенные навыки. См. [Desktop](../desktop.mdx). Skills из [расширения](../develop/extensions.mdx) доступны только при включённом расширении и не появляются в этом списке настроек.
