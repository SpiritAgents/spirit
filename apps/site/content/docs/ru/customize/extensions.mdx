Расширения добавляют Spirit новые возможности — инструменты, навыки, хуки, MCP-серверы и вклад в интерфейс. Они распространяются через маркетплейсы расширений:

- **Встроенные** — поставляются с приложением.
- **Личные** — ваши собственные импорты: ZIP-пакеты, которые вы добавили сами.
- **Удалённые маркетплейсы расширений** — добавляются вами: Git-репозиторий, URL HTTP-индекса или локальный каталог.

На Desktop страница **Расширения** в боковой панели показывает по вкладке на каждый маркетплейс, а вкладка **Все** объединяет все маркетплейсы в один список. В CLI те же сценарии доступны через команды `spirit extension` и TUI `/extension marketplace`.

## Установка, обновление и удаление

На Desktop откройте **Расширения**, выберите расширение и нажмите **Установить**. У установленного расширения есть меню **Другие действия** с пунктами **Отключить** (выключает без удаления) и **Удалить**. Когда маркетплейс публикует более новую версию, на странице сведений появляется кнопка **Обновить**.

В CLI:

```bash
spirit extension list
spirit extension install <name>
spirit extension update <name>
spirit extension remove <id>
```

`install` разрешает `<name>` по всем добавленным маркетплейсам. Если два маркетплейса предлагают одно и то же имя, команда завершится ошибкой и перечислит их — повторите с `--marketplace <name>`, чтобы выбрать один. Одно и то же имя, установленное из разных маркетплейсов, сосуществует: установки изолированы по маркетплейсам.

Встроенные расширения обновляются автоматически вместе с приложением. У личных (импортированных) расширений нет источника для обновления — просто импортируйте более новый ZIP заново.

## Подтверждение проверки

Установка или обновление расширения, чья запись в маркетплейсе не проверена — или была отозвана — требует явного подтверждения. На Desktop показывается диалог **Проверка расширения**; CLI требует `--review-acknowledged`, а TUI показывает шаг подтверждения.

## Импорт расширения (ZIP)

ZIP-пакет — это самодекларируемый обходной канал: без участия маркетплейса.

- Desktop: страница **Расширения** → **Добавить** → **Импортировать расширение**, затем выберите ZIP-файл.
- CLI: `spirit extension import <archive>`.

Импорты попадают в маркетплейс **Личные** как непроверенные записи и проходят то же подтверждение проверки. Повторный импорт того же имени перезаписывает его, а удаление импортированного расширения также удаляет его запись в Личных.

## Добавление маркетплейса

- Desktop: страница **Расширения** → **Добавить** → **Добавить маркетплейс** → **Добавить с диска…** (локальный каталог) или **Добавить по URL…** (Git-репозиторий или URL HTTP-индекса).
- CLI: `spirit extension marketplace add <url|path>`.

Три формы локатора:

| Форма                           | Пример                                                                   |
| ------------------------------- | ------------------------------------------------------------------------ |
| Локальный каталог               | `spirit extension marketplace add ./my-marketplace`                      |
| Git-репозиторий (HTTPS или SSH) | `spirit extension marketplace add git@github.com:octocat/extensions.git` |
| URL HTTP-индекса                | `spirit extension marketplace add https://example.com`                   |

Git-URL принимают `--git-ref <tag|branch|commit>` для фиксации ref; по умолчанию используется ветка удалённого репозитория по умолчанию. Простой URL сайта автоматически дополняется до `/.spirit/marketplace.json`.

Управляйте добавленными маркетплейсами через `spirit extension marketplace list` и `spirit extension marketplace remove <name>`. На Desktop действие удаления доступно по правому клику на вкладке маркетплейса.

<Callout type="info">
  Заявленные возможности расширения подтверждает его маркетплейс, а не сам пакет. Добавить
  маркетплейс — значит доверить проверку его оператору: добавляйте только те источники, которым
  доверяете.
</Callout>
