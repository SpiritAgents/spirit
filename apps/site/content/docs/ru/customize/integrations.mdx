---
title: Интеграции
description: Вход через GitHub Device. Токен хранится в связке ключей.
---

**Настройки → Интеграции** подключают GitHub через OAuth device flow. Вы подтверждаете в браузере; {{product.name|mdx}} хранит токен в системной связке ключей в службе `{{product.name}}`.

Полная панель доступна в приложении Electron. В других оболочках может отображаться ограниченное уведомление.

GitHub обязателен, чтобы [Автоматизации](./automations.mdx) могли срабатывать по pull request'ам или issue. Отключение GitHub убирает этот путь триггера; существующие автоматизации по времени продолжают работать.
