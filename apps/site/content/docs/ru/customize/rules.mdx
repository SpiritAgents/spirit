Правила — это Markdown, который агент всегда учитывает. Есть три слота:

| Область                        | Путь                          |
| ------------------------------ | ----------------------------- |
| Файл агента рабочей области    | `{workspace}/AGENTS.md`       |
| Правило {{product.name|mdx}} рабочей области | `{workspace}/{{product.workspaceDataFolderName}}/rule.md` |
| Пользовательское правило       | `{spiritDataDir}/rule.md`     |

Записывайте конвенции проекта в `AGENTS.md`, чтобы любой, кто открывает репозиторий, их видел. Используйте `{{product.workspaceDataFolderName}}/rule.md` для заметок, специфичных для {{product.name|mdx}}, которые вы не хотите помещать в общий файл агента. Используйте пользовательское правило для предпочтений, которые следуют за вами между рабочими областями.

Управляйте слотами в **Настройки → Правила**. Встроенный навык `create-rule` может составить файл правил за вас. Rule из [расширения](../develop/extensions.mdx) применяется только при включённом расширении и не появляется в этом списке настроек.
