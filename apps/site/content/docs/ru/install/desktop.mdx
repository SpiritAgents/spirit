title: Установка Desktop
description: Загрузите Spirit для macOS, Windows или Linux.
---

Desktop — это графический хост: чат, файлы рабочей области, Git, настройки, расширения и автоматизации. Он использует общий локальный демон с [CLI](./cli.mdx).

## Загрузка

Используйте [страницу загрузки](/en-US/download). Она выбирает сборку для вашей ОС и архитектуры с `download.spirit.dev`.

| Платформа | Файл          | Архитектуры      |
| --------- | ------------- | ---------------- |
| macOS     | `.dmg`        | x64, arm64       |
| Windows   | `.exe` (NSIS) | x64, arm64, ia32 |
| Linux     | `.AppImage`   | x64, arm64       |

Вы также можете взять релиз с GitHub из [последнего](https://github.com/SpiritAgents/spirit/releases/latest). В релизах для Linux может быть `.deb` в дополнение к AppImage.

Не существует официального пакета Homebrew, winget или apt для Desktop.

## После установки

1. Откройте Spirit.
2. [Откройте рабочую область](../quickstart.mdx#2-open-a-workspace).
3. Подключите провайдера в **Settings → Models**. Ключ сохраняется в системную связку ключей.

На macOS, если Gatekeeper блокирует первый запуск, откройте приложение из Finder с помощью Control-click → Open.

В Linux сделайте AppImage исполняемым (`chmod +x Spirit-linux-*.AppImage`) перед запуском.

## Обновления

Страница загрузки и путь CDN `latest` всегда указывают на текущую сборку Desktop. Релизы GitHub хранят версионированные артефакты, если вам нужно зафиксировать версию.
