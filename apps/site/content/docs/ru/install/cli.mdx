CLI — это терминальный хост с TUI и неинтерактивным режимом `-p`. Он общается с тем же локальным демоном, что и [Desktop](./desktop.mdx).

## Скрипт установки

macOS и Linux:

```bash
curl -fsSL {{product.websiteOrigin}}/install | bash
```

Windows (PowerShell):

```powershell
irm {{product.websiteOrigin}}/install.ps1 | iex
```

Скрипт загружает сборку с `{{product.downloadOrigin|host}}`, сверяет SHA-256 с `SHA256SUMS.txt` соответствующего GitHub Release (при несовпадении установка прерывается), распаковывает её и добавляет `spirit` в ваш `PATH`.

Откройте новый терминал, затем:

```bash
spirit --version
```

## Куда это устанавливается

Бинарные файлы CLI используют SPIRIT_HOME. В Unix установка Stable и общие данные могут иметь один родительский каталог; bin/ и cli/ остаются файлами установки. Эта настройка не определяет каталог общих данных.

|                                                     | По умолчанию                                                                                                 | Переопределение   |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------- |
| Бинарные файлы CLI                                  | Unix: `~/.spirit` · Windows: `%LOCALAPPDATA%\Spirit`                                                         | `SPIRIT_HOME`     |
| Сессии, конфигурация, указатели на хранилище ключей | Stable: `~/{{product.stable.userDataFolderName}}` · Dev: `~/{{product.dev.userDataFolderName}}` · Windows: `%USERPROFILE%\{{product.stable.userDataFolderName}}` / `%USERPROFILE%\{{product.dev.userDataFolderName}}` | `SPIRIT_DATA_DIR` |

В Unix скрипт создаёт ссылку `$SPIRIT_HOME/bin/spirit` → `$SPIRIT_HOME/cli/current/bin/spirit` и добавляет `export PATH="$SPIRIT_HOME/bin:$PATH"` в `~/.profile`, `~/.bashrc` и `~/.zshrc` (маркер `# spirit cli`).

## Зафиксировать версию или зеркало

| Переменная             | По умолчанию                            | Роль                                     |
| ---------------------- | --------------------------------------- | ---------------------------------------- |
| `SPIRIT_HOME`          | `~/.spirit` или `%LOCALAPPDATA%\Spirit` | Корень установки для бинарных файлов CLI |
| `SPIRIT_VERSION`       | `latest`                                | Сегмент версии в URL загрузки            |
| `SPIRIT_DOWNLOAD_HOST` | `{{product.downloadOrigin|host}}`                   | Хост CDN                                 |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL {{product.websiteOrigin}}/install | bash
```

Вы также можете загрузить архив CLI со [страницы загрузки](/en-US/download) или [GitHub Releases](https://github.com/SpiritAgents/spirit/releases/latest) и распаковать его самостоятельно.

## Первый запуск

```bash
cd /path/to/your/project
spirit
```

Это открывает TUI. Добавьте провайдера с помощью `/model add` или из оболочки с помощью `spirit model add`. См. [краткое руководство](../quickstart.mdx).
