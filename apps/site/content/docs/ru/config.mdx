Каталог общих пользовательских данных определяется quality сборки, а не каталогом приложений операционной системы.

## Каталог данных

Переопределяется с помощью `SPIRIT_DATA_DIR`. Сервер также может использовать `SPIRIT_SERVER_DATA_DIR` (имеет приоритет над первым).

| Сборка | macOS / Linux | Windows |
| --- | --- | --- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev | `~/{{product.dev.userDataFolderName}}` | `%USERPROFILE%\{{product.dev.userDataFolderName}}` |

Breaking Change: старые каталоги платформы не читаются и не переносятся автоматически. Явное указание каталога данных по-прежнему поддерживается. Кеш Electron, хранилище браузера и состояние окон остаются в частном каталоге приложения платформы.

Типичные файлы:

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

Бинарные файлы CLI используют SPIRIT_HOME. В Unix установка Stable и общие данные могут иметь один родительский каталог; bin/ и cli/ остаются файлами установки. Эта настройка не определяет каталог общих данных.

## config.json v2

`schemaVersion` должен быть `2`. Версия 1 отклоняется — удалите старый файл и [подключите провайдера](./providers.mdx).

Основные поля:

- `providerGroups` — подключенные дома, базовый API, транспорт, модели
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `lightweightChatModel`

Ключи **не** хранятся в этом файле. Они находятся в [связке ключей](./security.mdx).

## Workspace `{{product.workspaceDataFolderName}}/`

| Путь                 | Роль                                               |
| -------------------- | -------------------------------------------------- |
| `{{product.workspaceDataFolderName}}/rule.md`    | Правила workspace [правила](./customize/rules.mdx) |
| `{{product.workspaceDataFolderName}}/skills/`    | Навыки workspace [навыки](./customize/skills.mdx)  |
| `{{product.workspaceDataFolderName}}/mcp.json`   | MCP workspace [MCP](./customize/mcp.mdx)           |
| `{{product.workspaceDataFolderName}}/hooks.json` | Хуки workspace [хуки](./customize/hooks.mdx)       |

Также используются: `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## Переменные окружения

| Переменная                                                        | Роль                                           |
| ----------------------------------------------------------------- | ---------------------------------------------- |
| `SPIRIT_DATA_DIR`                                                 | Каталог данных                                 |
| `SPIRIT_SERVER_DATA_DIR`                                          | Каталог данных сервера (приоритет)             |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                               |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | Установщик CLI                                 |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | Переопределения для процессов [CLI](./cli.mdx) |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | Хост веб-интерфейса Desktop                    |
| `SPIRIT_TERMINAL_SHELL`                                           | PTY-оболочка Desktop                           |
