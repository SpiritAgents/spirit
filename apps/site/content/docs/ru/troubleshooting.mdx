## config.json отклонён

Файл должен иметь `schemaVersion: 1`. Любая другая версия отклоняется — удалите старый файл и [подключите провайдера заново](./providers.mdx). Если вы не объявили `apiKey` открытым текстом, ключей в этом файле нет — они находятся в [связке ключей](./security.mdx).

## CLI установлен, настройки пусты

Вы установили бинарники в `SPIRIT_HOME` (`~/.spirit`). Сессии и `config.json` находятся в [каталоге данных](./config.mdx). Проверьте `SPIRIT_DATA_DIR`, если вы его переопределили.

## `spirit -p` завершился с ошибкой

- Требуется одобрение → используйте `-a auto-approval` / `-a bypass-approval` или TUI
- Требуется [ask_questions](./agent/ask-questions.mdx) → используйте TUI или сделайте запрос более решительным
- Истекло время ожидания → headless останавливается через 30 минут

## Модели не импортировались

Откройте [страницу провайдера](./providers.mdx) для этого провайдера. Проверьте сайт, конечную точку плана, ресурс Azure, учётную запись Cloudflare, регион Bedrock / IAM или проект Vertex / местоположение. TokenHub остаётся на Chat Completions. Bedrock Bearer не может перечислять модели.

## Ключ отсутствует в связке ключей

Подключитесь заново в **Настройки → Модели** или с помощью `spirit model add`. Мастер записывает связку ключей **до** `config.json`. Не вставляйте ключи в репозиторий.

## Сопряжение Web Host не удалось

Неправильный код → попробуйте снова. Пять неудачных попыток блокируют сопряжение (`PAIRING_LOCKED`) до перезапуска Web Host в **Настройки → Сети**. Хост должен поддерживать сопряжение; универсальный веб-превью может показать, что это не так.

## LSP отсутствует

Установите сервер самостоятельно (clangd через Homebrew / winget, jdtls вручную), затем включите его в **Настройки → Агенты**. См. [Desktop](./desktop.mdx).

## Автодополнение Tab пусто

Включите **Настройки → Tab** и назначьте вспомогательную языковую модель. См. [Desktop](./desktop.mdx).

## ACP отсутствует на странице загрузки

Это ожидаемо. ACP реализован, но колонка загрузки всё ещё является заполнителем. См. [ACP](./acp.mdx).
