CLI — это терминальный хост. Установите его с помощью [скрипта установки](./install/cli.mdx). Он общается с тем же демоном, что и [Desktop](./desktop.mdx).

## TUI

```bash
cd /path/to/your/project
spirit
```

Макет может быть `inline` или `fullscreen` (`-t` / `--tui`, или `/tui`). Режимы, подтверждения и Loop соответствуют Desktop.

Полезные слеш-команды: `/help`, `/quit`, `/new`, `/continue`, `/loop`, `/model`, `/session`, `/rewind`, `/fork`, `/subagent`, `/approval`, `/mcp`, `/hook`, `/rule`, `/skill`, `/extension`.

## Неинтерактивный режим

```bash
spirit -p "your prompt here"
```

Только окончательный текст ассистента выводится в stdout. Поместите `-m`, `-a` и `-l` **перед** `-p`. Процесс завершается с ошибкой, если вызов требует подтверждения или [ask_questions](./agent/ask-questions.mdx). В автономном режиме происходит тайм-аут через 30 минут.

## Переменные окружения

| Переменная        | Роль                                                                            |
| ----------------- | ------------------------------------------------------------------------------- |
| `SPIRIT_API_KEY`  | API-ключ для этого процесса. Порядок: env → keyring модели → глобальный keyring |
| `SPIRIT_API_BASE` | Переопределение базового URL API                                                |
| `SPIRIT_DATA_DIR` | Каталог данных (то же хранилище, что и у Desktop)                               |
| `SPIRIT_HOME`     | Корень установки **бинарного** файла CLI — не каталог данных                    |

## Общий демон

`spirit` подключается через WebSocket к демону Spirit Server. Сессии, потоковая передача, инструменты и очередь подтверждений находятся там. Bearer-токен — `{spiritDataDir}/server.token` (режим `0600`). По умолчанию демон привязывается к `127.0.0.1` на случайном порту.

`spirit serve` запускает демон в фоновом режиме. Удаленный `0.0.0.0` не является открытым продуктовым путем. См. [Безопасность](./security.mdx).

## Команды

```
spirit [-v] [-m model] [-a approval] [-l language] [-t inline|fullscreen] [-p prompt]
spirit interactive
spirit serve
spirit model list|add|remove|use|current
spirit config show|set-base|set-image-model|clear-image-model|set-video-model|clear-video-model|key set|remove|status
spirit mcp …
spirit hook list|validate
spirit extension list|import|remove …
```
