Spirit — это BYOK. Вы создаете ключ в консоли провайдера, вставляете его в Desktop или CLI, и Spirit хранит его в связке ключей операционной системы. Смена домов не меняет способ открытия рабочей области, одобрения правок или запуска агента.

Мастер подключения находится в **Settings → Models** в Desktop или в `/model add` / `spirit model add` в CLI. Дополнительные поля появляются только тогда, когда они нужны данному провайдеру.

Spirit общается с провайдерами через один из четырех транспортов. Мастер либо фиксирует тип, либо позволяет выбрать.

| Транспорт           | Метка в мастере                    | Типичное использование                                                     |
| ------------------- | ---------------------------------- | -------------------------------------------------------------------------- |
| `openai-compatible` | Chat Completions API               | Большинство OpenAI-совместимых конечных точек                              |
| `open-responses`    | Responses API / Open Responses API | OpenAI, Azure, Vercel AI Gateway, Hugging Face и необязательные пути шлюза |
| `anthropic`         | Messages API                       | Anthropic, MiniMax и необязательные Messages-совместимые конечные точки    |
| `bedrock`           | Amazon Bedrock                     | Только Amazon Bedrock                                                      |

Google Gemini и Vertex AI всегда используют Chat Completions. Если профиль запрашивает Responses или Messages, Spirit откатывается к `openai-compatible`.

Некоторые дома добавляют второе измерение поверх ключа:

- **Региональные сайты** — Moonshot AI, SiliconFlow, MiniMax (Китай / Международный); Alibaba (регион + `workspaceId`); Tencent TokenHub (Гуанчжоу / Сингапур)
- **Тарифные конечные точки** — Alibaba Token Plan, StepFun Step Plan, Z.ai / Zhipu AI GLM Coding Plan
- **Облачные поля** — регион Bedrock, имя ресурса Azure, аккаунт Cloudflare (и необязательный шлюз), проект / местоположение Vertex

Если у провайдера нет ни одного из этих полей, мастер — это просто ключ → импорт моделей → выбор активной чат-модели.

Spirit импортирует каталог моделей и позволяет назначить активную чат-модель, а также слоты для изображений, видео и облегченного чата, если каталог помечает эти возможности. Рассуждения и встроенный веб-поиск следуют за моделью и транспортом, а не за отдельным переключателем Spirit.

## Каталог

Это дома в списке подключения, в том же порядке. Каждый раздел — это ключ, транспорт и дополнительные поля дома. Мастер в Desktop и CLI одинаков для всех домов.

### OpenAI

Создайте API-ключ в [платформе OpenAI](https://platform.openai.com/api-keys). Spirit не продает использование OpenAI.

Мастер фиксирует **Responses API** (`open-responses`). Выбора транспорта нет. Базовый URL по умолчанию: `https://api.openai.com/v1`.

Чат после импорта. Рассуждения следуют за моделью. Генерация изображений и видео появляется только тогда, когда каталог отмечает эти возможности — назначьте их в слотах моделей изображений / видео.

### Anthropic

Создайте API-ключ в [консоли Anthropic](https://console.anthropic.com/settings/keys).

Фиксированный **Messages API** (`anthropic`). Базовый URL по умолчанию: `https://api.anthropic.com/v1`.

Чат после импорта. Рассуждения следуют за моделью. Нет слота генерации изображений или видео на стороне Spirit, если только более поздняя запись каталога не отметит это.

### Google

Создайте API-ключ в [Google AI Studio](https://aistudio.google.com/apikey).

Фиксированный **Chat Completions API** (`openai-compatible`). Запрос Responses или Messages откатывается к Chat Completions. Базовый URL по умолчанию: `https://generativelanguage.googleapis.com/v1beta`.

Чат после импорта. Генерация изображений назначается только тогда, когда это отмечено в каталоге. Для Vertex AI (проект / местоположение GCP) используйте [Google Vertex AI](#google-vertex-ai).

### SpaceXAI

Создайте API-ключ в [консоли SpaceXAI](https://console.x.ai/team/default/api-keys).

Фиксированный **Chat Completions API** (`openai-compatible`). Базовый URL по умолчанию: `https://api.x.ai/v1`.

Чат после импорта. Рассуждения, изображения и видео следуют импортированному каталогу — назначайте слоты, когда они появляются.

### Vercel AI Gateway

Создайте ключ в панели управления [Vercel AI Gateway](https://vercel.com/docs/ai-gateway).

Фиксированный **Open Responses API** (`open-responses`). Базовый URL по умолчанию: `https://ai-gateway.vercel.sh/v1`.

Чат плюс всё, что предоставляет каталог шлюза. Генерация изображений берётся из каталога `type=image`, а не из тегов.

Не определяйте наличие зрения или генерации изображений по тегам. MiniMax M3 через этот шлюз не возвращает отображаемый поток рассуждений в Open Responses.

### Cloudflare AI Gateway

Создайте API-токен в [панели управления Cloudflare](https://developers.cloudflare.com/ai-gateway/). Также вам понадобится идентификатор аккаунта.

Выбор: **Chat Completions**, **Open Responses** или **Messages**. Базовый URL строится из аккаунта: `https://api.cloudflare.com/client/v4/accounts/{accountId}/ai/v1`.

- **ID аккаунта** (обязательно) — 32-символьный шестнадцатеричный
- **ID шлюза** (необязательно)

Без ID аккаунта мастер не сможет построить базовый URL API. Чат и другие возможности следуют моделям, которые предоставляет шлюз.

Выбора нет. Значение подключения по умолчанию — **Open Responses** (`open-responses`). Совместимые базовые URL также существуют по адресам `https://api.deepseek.com/v1` (Chat) и `https://api.deepseek.com/anthropic` (Messages).

Чат после импорта. Рассуждения следуют модели.

- **ap-southeast-1** — требуется идентификатор рабочей области
- **us-virginia** — `https://dashscope-us.aliyuncs.com/compatible-mode/v1` (без идентификатора рабочей области)

### Azure

Создайте ключ для ресурса Azure OpenAI на [портале Azure](https://portal.azure.com).

Исправлена **Ответы API** (`open-responses`). Без выбора транспорта.

- **Имя ресурса** (обязательно) — 2–64 символа, буквы, цифры и дефисы; не может начинаться или заканчиваться дефисом

Spirit формирует `https://{resource}.openai.azure.com/openai/v1`. Чат после импорта. Генерация изображений следует каталогу Azure, если отмечено.

### Amazon Bedrock

В [консоли AWS Bedrock](https://console.aws.amazon.com/bedrock) создайте Bearer API-ключ или пользователя IAM, который может вызывать Bedrock.

Исправлен **Amazon Bedrock** (`bedrock`). Форма хоста по умолчанию: `https://bedrock.us-east-1.amazonaws.com`.

- **Регион AWS** (обязательно), например `us-east-1`
- **Аутентификация**: **Bearer** или **IAM**
  - Bearer — вставьте API-ключ Bedrock и идентификатор модели. Модели **не** извлекаются автоматически.
  - IAM — идентификатор ключа доступа + секретный ключ доступа. Spirit перечисляет базовые модели из аккаунта.

Чат после выбора модели. Другие возможности следуют за моделью. Ключи Bearer работают только для вывода. `ListFoundationModels` не принимает Bearer, поэтому импорт каталога требует IAM.

### Google Vertex AI

Используйте проект GCP с включенным Vertex AI. Аутентификация — ADC, сервисный аккаунт или ключ Express API, а не универсальный ключ OpenAI.

Исправлен **Chat Completions API**. Запросы Responses или Messages переходят на Chat Completions. Базовый URL становится `https://{location}-aiplatform.googleapis.com/v1/projects/{project}/locations/{location}`.

- **Идентификатор проекта GCP** и **Расположение** (обязательно), например `us-central1`
- **Аутентификация**
  - **ADC** — Учетные данные приложения по умолчанию на этом компьютере (`GOOGLE_APPLICATION_CREDENTIALS`)
  - **Сервисный аккаунт** — адрес электронной почты клиента + закрытый ключ; используется для получения списка моделей
  - **Ключ Express API** — не может извлекать каталог; добавьте идентификатор модели вручную

Чат после выбора модели. Для ключей AI Studio без проекта GCP используйте [Google](#google). Express-режим не может импортировать список моделей. Режим сервисного аккаунта требует и адрес электронной почты, и закрытый ключ для вывода списка моделей.

### Пользовательский

Используйте ключ API, ожидаемый вашей конечной точкой. У Spirit нет пользовательского провайдера, размещенного на его серверах.

Выбор: **Chat Completions**, **Open Responses** или **Messages**. Вы должны указать **Базовый URL**. Если оставить поле пустым, по умолчанию используется `https://api.openai.com/v1`.

Введите корень, документированный поставщиком, включая суффикс версии, если он требуется (`/v1`, `/v1/openai`, …). Spirit не угадывает путь для пользовательских конечных точек.

Вы также можете задать отображаемое имя для группы провайдеров, чтобы несколько пользовательских конечных точек оставались различимыми.

После подключения импортируйте или введите идентификаторы моделей. Отметьте возможности чата / изображений / видео в мастере, если конечная точка не публикует каталог, который понимает Spirit.
