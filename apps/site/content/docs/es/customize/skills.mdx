Una Skill es una carpeta con un `SKILL.md`. {{product.name|mdx}} descubre Skills desde tres lugares:

| Alcance                         | Ruta                                                                     |
| ------------------------------- | ------------------------------------------------------------------------ |
| Usuario                         | `{spiritDataDir}/skills/{name}/SKILL.md`                                 |
| Espíritu del espacio de trabajo | `{workspace}/{{product.workspaceDataFolderName}}/skills/{name}/SKILL.md` |
| agentes del espacio de trabajo  | `{workspace}/.agents/skills/{name}/SKILL.md`                             |

Cuando mencionas una Skill en un turno, {{product.name|mdx}} puede adjuntar su texto completo a ese mensaje de usuario. No vierte cada Skill en el prompt del sistema.

## Frontmatter

`SKILL.md` debe comenzar con Frontmatter. Un archivo sin `name` o `description` no se descubre.

| Campo         | Descripción                                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`        | Obligatorio. Nombre de la Skill; debe coincidir con el nombre de la carpeta. 1–64 caracteres, solo letras minúsculas, dígitos y guiones |
| `description` | Obligatorio. Descripción breve                                                                                                              |

## Skills integradas

Estas vienen con {{product.name|mdx}} (no son archivos en tu directorio de datos):

- `create-rule` — redacta una [regla](./rules.mdx)
- `create-skill` — redacta una [Skill](./skills.mdx)
- `create-hook` — redacta un [hook](./hooks.mdx)
- `create-extension` — redacta una [extensión](../develop/extensions.mdx)

Gestiona las Skills en **Ajustes → Skills**. Los chips de git commit / push / merge son de la interfaz del host, no Skills incluidas. Consulta [Desktop](../desktop.mdx). Las Skills empaquetadas en una [extensión](../develop/extensions.mdx) están disponibles cuando esa extensión está habilitada. No aparecen en esta lista de ajustes.
