---
title: Integraciones
description: Inicio de sesión de dispositivo GitHub. El token se guarda en el llavero.
---

**Configuración → Integraciones** conecta GitHub con el flujo de dispositivo OAuth. Apruebas en el navegador; {{product.name|mdx}} guarda el token en el llavero del sistema bajo el servicio `{{product.name}}`.

El panel completo está disponible en la aplicación Electron. Otros shells pueden mostrar un aviso limitado.

GitHub es necesario antes de que [Automatizaciones](./automations.mdx) pueda activarse en solicitudes de extracción o problemas. Desconectar GitHub elimina esa ruta de activación; las automatizaciones de tiempo existentes siguen ejecutándose.
