## Proveedores de modelos

{{product.name|mdx}} no proporciona servicios de modelos directamente. Puedes conectar OpenAI, Anthropic, SpaceXAI, una puerta de enlace o un proveedor regional. Cada proveedor opera bajo el mismo entorno: las herramientas, las aprobaciones, las sesiones y el comportamiento del espacio de trabajo se mantienen consistentes.

Las claves se escriben en el llavero del sistema bajo el servicio `{{product.name}}`. No se almacenan en `config.json`.

## Un agente, dos anfitriones

Desktop y la CLI comparten un demonio local. Las sesiones, los modelos, las aprobaciones y las credenciales residen en el mismo directorio de datos, por lo que puedes iniciar una tarea en la aplicación y continuarla en la terminal.

## Comienza aquí

1. [Instala Desktop o la CLI](./quickstart.mdx)
2. Abre un espacio de trabajo
3. Conecta un proveedor
4. Pide al agente que lea el repositorio, haga un pequeño cambio y apruebe la modificación
