---
title: Apariencia
description: Tema, fuentes y los diez idiomas de la interfaz.
---

Abre **Configuración → Apariencia**.

## Tema

`system`, `light` o `dark`. Se guarda como `spirit-desktop-theme`.

## Fuente

La predeterminada es la fuente del sistema. Puedes cambiar a una familia personalizada.

## Idiomas de la interfaz

La interfaz de Desktop / CLI tiene **diez** idiomas. El predeterminado es chino simplificado.

| Código  | Idioma                    |
| ------- | ------------------------- |
| `zh-CN` | 简体中文 (predeterminado) |
| `en`    | Inglés                    |
| `zh-TW` | 繁體中文                  |
| `ja`    | 日本語                    |
| `ko`    | 한국어                    |
| `de`    | Alemán                    |
| `fr`    | Francés                   |
| `es`    | Español                   |
| `pt-BR` | Portugués de Brasil       |
| `ru`    | Ruso                      |

Otros conmutadores de apariencia (mica / desenfoque, puntero) permanecen en la misma página de configuración.
