ACP (Protocolo de Cliente Agente) está implementado como `spirit-acp` (`@spiritagent/acp-server`). Habla stdio ndJSON, comparte el mismo directorio de datos y llavero que Desktop y CLI, y puede ejecutar `--setup` para conectar un proveedor.

**La página pública de descarga aún no lista ACP.** {{product.name|mdx}} todavía se está preparando para listarlo en el registro de ACP.

## Configuración temporal antes del listado

Hasta que se liste, instale y complete la configuración con `npx`:

```bash
npx @spiritagent/acp-server --setup
```

O apunte un cliente ACP (por ejemplo, Zed) a la entrada stdio:

```json
"agent_servers": {
  "{{product.name}}": {
    "command": "node",
    "args": ["path/to/packages/acp-server/dist/src/stdio-entry.js"]
  }
}
```

Autentique con **Ejecutar en terminal**, complete `--setup`, luego `authenticate` y `session/new`.

| Variable               | Rol                                                                                                |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| `SPIRIT_ACP_WORKSPACE` | Raíz del espacio de trabajo (por defecto, el cwd del cliente)                                      |
| `SPIRIT_ACP_DATA_DIR`  | Directorio de datos; de lo contrario, `SPIRIT_DATA_DIR` y luego el predeterminado de la plataforma |
