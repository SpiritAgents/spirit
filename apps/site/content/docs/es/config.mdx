El directorio de datos de usuario compartidos depende de la quality del build, no del directorio de aplicaciones del sistema.

## Directorio de datos

Se puede sobrescribir con `SPIRIT_DATA_DIR`. El servidor también puede usar `SPIRIT_SERVER_DATA_DIR` (que tiene prioridad sobre el anterior).

| Build  | macOS / Linux                             | Windows                                               |
| ------ | ----------------------------------------- | ----------------------------------------------------- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev    | `~/{{product.dev.userDataFolderName}}`    | `%USERPROFILE%\{{product.dev.userDataFolderName}}`    |

Breaking Change: los directorios anteriores no se leen ni migran automáticamente. Se mantienen las opciones explícitas para cambiar el directorio de datos. Las cachés de Electron, el almacenamiento del navegador y el estado de las ventanas permanecen en el directorio privado de la plataforma.

Archivos típicos:

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

Los binarios CLI usan SPIRIT_HOME. En Unix, la instalación Stable y los datos compartidos pueden tener el mismo directorio padre; bin/ y cli/ siguen siendo archivos de instalación. Este ajuste no selecciona el directorio de datos compartidos.

## config.json v2

`schemaVersion` debe ser `2`. La versión 1 se rechaza: elimina el archivo antiguo y [vuelve a conectar un proveedor](./providers.mdx).

Campos principales:

- `providerGroups` — casas conectadas, base de API, transporte, modelos
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `secondaryLanguageModel`
- `permission` — reglas de la lista de permitidos

Las claves **no** están en este archivo. Viven en el [keyring](./security.mdx).

### permission

`permission` fija qué pueden hacer comandos shell y rutas de archivo individuales, además del [nivel de aprobación](./agent/approvals.mdx) de la sesión. Las claves son nombres de herramientas (`shell`, `read_file`); los valores asignan patrones con comodines a `allow`, `ask` o `deny`.

```json
{
  "permission": {
    "shell": {
      "git *": "allow",
      "rm -rf *": "deny"
    }
  }
}
```

`deny` es absoluto — ningún nivel de aprobación, Hook o memoria de sesión lo anula. La sintaxis de patrones, la semántica de rutas y la lista completa de acciones están en [Aprobaciones](./agent/approvals.mdx). Verifica las reglas sin ejecutar nada: `spirit permission check --shell "git status"`.

El antiguo `tool-permissions.json` (escrito por el botón «Confiar siempre») está obsoleto: el código ya no lo lee ni lo escribe, y no hay migración automática. Los archivos sobrantes son inertes — elimínalos manualmente.

## Espacio de trabajo `{{product.workspaceDataFolderName}}/`

| Ruta                                             | Rol                                                          |
| ------------------------------------------------ | ------------------------------------------------------------ |
| `{{product.workspaceDataFolderName}}/rule.md`    | Regla del [espacio de trabajo](./customize/rules.mdx)        |
| `{{product.workspaceDataFolderName}}/skills/`    | Skills del [espacio de trabajo](./customize/skills.mdx) |
| `{{product.workspaceDataFolderName}}/mcp.json`   | MCP del [espacio de trabajo](./customize/mcp.mdx)            |
| `{{product.workspaceDataFolderName}}/hooks.json` | Hooks del [espacio de trabajo](./customize/hooks.mdx)        |

También se usan: `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## Variables de entorno

| Variable                                                          | Rol                                     |
| ----------------------------------------------------------------- | --------------------------------------- |
| `SPIRIT_DATA_DIR`                                                 | Directorio de datos                     |
| `SPIRIT_SERVER_DATA_DIR`                                          | Directorio de datos del servidor (gana) |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                        |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | Instalador de CLI                       |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | Overrides de proceso [CLI](./cli.mdx)   |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | Host web de escritorio                  |
| `SPIRIT_TERMINAL_SHELL`                                           | Shell PTY de escritorio                 |
