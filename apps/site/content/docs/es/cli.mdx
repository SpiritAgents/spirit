El CLI es un host de terminal. Instálalo con el [script de instalación](./install/cli.mdx). Habla con el mismo daemon que [Desktop](./desktop.mdx).

## TUI

```bash
cd /path/to/your/project
spirit
```

El diseño es `inline` o `fullscreen` (`-t` / `--tui`, o `/tui`). Los modos, aprobaciones y Loop coinciden con Desktop.

Comandos de barra útiles: `/help`, `/quit`, `/new`, `/continue`, `/loop`, `/model`, `/session`, `/rewind`, `/fork`, `/subagent`, `/approval`, `/mcp`, `/hook`, `/rule`, `/skill`, `/extension`.

## No interactivo

```bash
spirit -p "your prompt here"
```

Solo el texto final del asistente va a stdout. Pon `-m`, `-a` y `-l` **antes** de `-p`. El proceso falla si una llamada necesita aprobación o [ask_questions](./agent/ask-questions.mdx). Headless agota el tiempo de espera después de 30 minutos.

## Entorno

| Variable          | Rol                                                                            |
| ----------------- | ------------------------------------------------------------------------------ |
| `SPIRIT_API_KEY`  | Clave API para este proceso. Orden: env → llavero del modelo → llavero global  |
| `SPIRIT_API_BASE` | Anulación de la URL base de la API                                             |
| `SPIRIT_DATA_DIR` | Directorio de datos (mismo almacén que Desktop)                                |
| `SPIRIT_HOME`     | Directorio raíz de instalación del **binario** CLI — no el directorio de datos |

## Daemon compartido

`spirit` se conecta a través de WebSocket al daemon de Spirit Server. Las sesiones, la transmisión, las herramientas y la cola de aprobaciones viven allí. El token de portador es `{spiritDataDir}/server.token` (modo `0600`). El daemon se vincula a `127.0.0.1` en un puerto aleatorio por defecto.

`spirit serve` ejecuta el daemon en primer plano. `0.0.0.0` remoto no es una ruta de producto abierta. Consulta [Seguridad](./security.mdx).

## Comandos

```
spirit [-v] [-m model] [-a approval] [-l language] [-t inline|fullscreen] [-p prompt]
spirit interactive
spirit serve
spirit model list|add|remove|use|current
spirit config show|set-base|set-image-model|clear-image-model|set-video-model|clear-video-model|key set|remove|status
spirit mcp …
spirit hook list|validate
spirit extension list|import|remove …
```
