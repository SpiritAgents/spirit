title: Installer Desktop
description: Téléchargez Spirit pour macOS, Windows ou Linux.
---

Desktop est l'hôte graphique : chat, fichiers d'espace de travail, Git, paramètres, extensions et automatisations. Il partage le démon local avec le [CLI](./cli.mdx).

## Téléchargement

Utilisez la [page de téléchargement](/en-US/download). Elle sélectionne une version pour votre système d'exploitation et votre architecture à partir de `download.spirit.dev`.

| Plateforme | Fichier       | Architectures    |
| ---------- | ------------- | ---------------- |
| macOS      | `.dmg`        | x64, arm64       |
| Windows    | `.exe` (NSIS) | x64, arm64, ia32 |
| Linux      | `.AppImage`   | x64, arm64       |

Vous pouvez également obtenir une version GitHub depuis [latest](https://github.com/SpiritAgents/spirit/releases/latest). Les versions Linux peuvent inclure un fichier `.deb` en plus de l'AppImage.

Il n'existe pas de paquet officiel Homebrew, winget ou apt pour Desktop.

## Après l'installation

1. Ouvrez Spirit.
2. [Ouvrez un espace de travail](../quickstart.mdx#2-open-a-workspace).
3. Connectez un fournisseur dans **Paramètres → Modèles**. La clé est stockée dans le trousseau du système.

Sur macOS, si Gatekeeper bloque le premier lancement, ouvrez l'application depuis Finder avec Contrôle-clic → Ouvrir.

Sur Linux, marquez l'AppImage comme exécutable (`chmod +x Spirit-linux-*.AppImage`) avant de l'exécuter.

## Mises à jour

La page de téléchargement et le chemin `latest` du CDN pointent toujours vers la version Desktop actuelle. Les versions GitHub conservent des artefacts versionnés si vous avez besoin de fixer une version.
