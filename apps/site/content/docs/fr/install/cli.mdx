Le CLI est un hôte de terminal avec une IUT et un mode non interactif `-p`. Il communique avec le même démon local que [Desktop](./desktop.mdx).

## Script d'installation

macOS et Linux :

```bash
curl -fsSL {{product.websiteOrigin}}/install | bash
```

Windows (PowerShell) :

```powershell
irm {{product.websiteOrigin}}/install.ps1 | iex
```

Le script télécharge une version depuis `{{product.downloadOrigin|host}}`, vérifie son SHA-256 par rapport au `SHA256SUMS.txt` de la Release GitHub correspondante (échec en cas d'écart), la décompresse et place `spirit` dans votre `PATH`.

Ouvrez un nouveau terminal, puis :

```bash
spirit --version
```

## Où il atterrit

Les binaires CLI utilisent SPIRIT_HOME. Sous Unix, l'installation Stable et les données partagées peuvent avoir le même répertoire parent ; bin/ et cli/ restent des fichiers d'installation. Ce réglage ne choisit pas le répertoire des données partagées.

|                                                 | Défaut                                                                                                                                                                                                                | Remplacement      |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| Binaires CLI                                    | Unix : `~/.spirit` · Windows : `%LOCALAPPDATA%\Spirit`                                                                                                                                                                | `SPIRIT_HOME`     |
| Sessions, configuration, pointeurs de trousseau | Stable: `~/{{product.stable.userDataFolderName}}` · Dev: `~/{{product.dev.userDataFolderName}}` · Windows: `%USERPROFILE%\{{product.stable.userDataFolderName}}` / `%USERPROFILE%\{{product.dev.userDataFolderName}}` | `SPIRIT_DATA_DIR` |

Sur Unix, le script crée un lien `$SPIRIT_HOME/bin/spirit` → `$SPIRIT_HOME/cli/current/bin/spirit` et ajoute `export PATH="$SPIRIT_HOME/bin:$PATH"` à `~/.profile`, `~/.bashrc` et `~/.zshrc` (marqueur `# spirit cli`).

## Épingler une version ou un miroir

| Variable               | Défaut                                 | Rôle                                            |
| ---------------------- | -------------------------------------- | ----------------------------------------------- | -------- |
| `SPIRIT_HOME`          | `~/.spirit` ou `%LOCALAPPDATA%\Spirit` | Racine d'installation pour les binaires CLI     |
| `SPIRIT_VERSION`       | `latest`                               | Segment de version dans l'URL de téléchargement |
| `SPIRIT_DOWNLOAD_HOST` | `{{product.downloadOrigin|host}}`                                         | Hôte CDN |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL {{product.websiteOrigin}}/install | bash
```

Vous pouvez également télécharger une archive CLI depuis la [page de téléchargement](/en-US/download) ou les [versions GitHub](https://github.com/SpiritAgents/spirit/releases/latest) et la décompresser vous-même.

## Première exécution

```bash
cd /path/to/your/project
spirit
```

Cela ouvre l'IUT. Ajoutez un fournisseur avec `/model add`, ou depuis le shell avec `spirit model add`. Consultez le [guide de démarrage rapide](../quickstart.mdx).
