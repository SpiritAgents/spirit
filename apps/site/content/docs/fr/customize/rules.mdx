Les règles sont du Markdown que l'agent considère toujours. Il y a quatre emplacements :

| Portée                                | Chemin                       |
| ------------------------------------- | ---------------------------- | --------------------------------------------------------- |
| Fichier agents de l'espace de travail | `{workspace}/AGENTS.md`      |
| Règle {{product.name|mdx}} de l'espace de travail | `{workspace}/{{product.workspaceDataFolderName}}/AGENTS.md` |
| Règle utilisateur                     | `{spiritDataDir}/AGENTS.md`    |
| Agents utilisateur | `~/.agents/AGENTS.md` |

Écrivez les conventions du projet dans `AGENTS.md` afin que toute personne qui ouvre le dépôt les voie. Utilisez `{{product.workspaceDataFolderName}}/AGENTS.md` pour les notes spécifiques à {{product.name|mdx}} que vous ne souhaitez pas inclure dans le fichier agents générique. Utilisez la règle utilisateur pour les préférences qui vous suivent à travers les espaces de travail.

Gérez les emplacements dans **Paramètres → Règles**. Une Skill intégrée, `create-rule`, peut rédiger un fichier de règles pour vous. Une rule bundlée dans une [extension](../develop/extensions.mdx) s'applique lorsque cette extension est activée. Elle n'apparaît pas dans cette liste de paramètres.
