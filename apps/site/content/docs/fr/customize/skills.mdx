Une compétence est un dossier avec un `SKILL.md`. Spirit découvre les compétences à partir de trois emplacements :

| Portée                        | Chemin                                       |
| ----------------------------- | -------------------------------------------- |
| Utilisateur                   | `{spiritDataDir}/skills/{name}/SKILL.md`     |
| Espace de travail Spirit      | `{workspace}/.spirit/skills/{name}/SKILL.md` |
| Agents de l'espace de travail | `{workspace}/.agents/skills/{name}/SKILL.md` |

Lorsque vous mentionnez une compétence dans un tour, Spirit peut joindre son texte complet à ce message utilisateur. Il ne déverse pas chaque compétence dans le prompt système.

## Frontmatter

`SKILL.md` doit commencer par un frontmatter. Un fichier sans `name` ou `description` n'est pas découvert.

| Champ         | Description                                                                                                                              |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `name`        | Requis. Nom de la compétence ; doit correspondre au nom du dossier. 1 à 64 caractères, uniquement lettres minuscules, chiffres et tirets |
| `description` | Requis. Description courte                                                                                                               |

## Compétences intégrées

Celles-ci sont fournies avec Spirit (ce ne sont pas des fichiers dans votre répertoire de données) :

- `create-rule` — rédigez une [règle](./rules.mdx)
- `create-skill` — rédigez une [compétence](./skills.mdx)
- `create-hook` — rédigez un [hook](./hooks.mdx)
- `create-extension` — rédigez une [extension](../develop/extensions.mdx)

Gérez les compétences dans **Paramètres → Compétences**. Les pastilles Git commit / push / merge sont de l'interface hôte, pas des compétences groupées. Voir [Desktop](../desktop.mdx). Les skills bundlées dans une [extension](../develop/extensions.mdx) sont disponibles lorsque cette extension est activée. Elles n'apparaissent pas dans cette liste de paramètres.
