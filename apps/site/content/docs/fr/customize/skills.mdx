Une Skill est un dossier avec un `SKILL.md`. {{product.name|mdx}} découvre les Skills à partir de trois emplacements :

| Portée                           | Chemin                                       |
| -------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------ |
| Utilisateur                      | `{spiritDataDir}/skills/{name}/SKILL.md`     |
| Espace de travail {{product.name|mdx}}                                        | `{workspace}/{{product.workspaceDataFolderName}}/skills/{name}/SKILL.md` |
| Agents de l'espace de travail    | `{workspace}/.agents/skills/{name}/SKILL.md` |

Lorsque vous mentionnez une Skill dans un tour, {{product.name|mdx}} peut joindre son texte complet à ce message utilisateur. Il ne déverse pas chaque Skill dans le prompt système.

## Frontmatter

`SKILL.md` doit commencer par un frontmatter. Un fichier sans `name` ou `description` n'est pas découvert.

| Champ         | Description                                                                                                                              |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `name`        | Requis. Nom de la Skill ; doit correspondre au nom du dossier. 1 à 64 caractères, uniquement lettres minuscules, chiffres et tirets |
| `description` | Requis. Description courte                                                                                                               |

## Skills intégrées

Celles-ci sont fournies avec {{product.name|mdx}} (ce ne sont pas des fichiers dans votre répertoire de données) :

- `create-rule` — rédigez une [règle](./rules.mdx)
- `create-skill` — rédigez une [Skill](./skills.mdx)
- `create-hook` — rédigez un [Hook](./hooks.mdx)
- `create-extension` — rédigez une [extension](../develop/extensions.mdx)

Gérez les Skills dans **Paramètres → Skills**. Les pastilles Git commit / push / merge sont de l'interface hôte, pas des Skills groupées. Voir [Desktop](../desktop.mdx). Les Skills bundlées dans une [extension](../develop/extensions.mdx) sont disponibles lorsque cette extension est activée. Elles n'apparaissent pas dans cette liste de paramètres.
