title: Outils
description: Outils que l'agent peut appeler. Certains n'apparaissent que lorsque le modèle, l'emplacement ou le mode est admissible.
---

Ces outils opèrent sur l'espace de travail que vous avez ouvert. Le mode Demander peut lire et rechercher ; il ne peut pas créer, éditer, supprimer, appliquer des correctifs, exécuter `shell`, ni générer des images ou des vidéos.

| Outil             | Rôle                                                                                                                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `read_file`       | Lire un fichier, ou lire des images et des vidéos                                                                                                                          |
| `create_file`     | Créer un fichier                                                                                                                                                           |
| `edit_file`       | Modifier un fichier existant                                                                                                                                               |
| `delete_file`     | Supprimer un fichier                                                                                                                                                       |
| `apply_patch`     | Exposé lorsque le modèle et le transport sont éligibles (par exemple un modèle GPT fourni par OpenAI) ; remplace `create_file` / `edit_file` / `delete_file` sur ce chemin |
| `glob`            | Trouver des chemins par glob (respecte `.gitignore`)                                                                                                                       |
| `grep`            | Rechercher le contenu des fichiers (respecte `.gitignore`)                                                                                                                 |
| `ls`              | Lister un répertoire, non récursif. Le chemin doit être absolu                                                                                                             |
| `shell`           | Exécuter une commande avec `reason` et `command`. Le mode Demander ne peut pas l'appeler                                                                                   |
| `web_fetch`       | Récupérer une URL `http` ou `https` et renvoyer du Markdown. Un outil hôte, pas une recherche de fournisseur                                                               |
| `generate_image`  | Exposé après avoir attribué un modèle d'image dans **Paramètres → Modèles**. Génère une image. Le mode Demander ne peut pas l'appeler                                      |
| `generate_video`  | Exposé après avoir attribué un modèle vidéo dans **Paramètres → Modèles**. Génère une courte vidéo. Le mode Demander ne peut pas l'appeler                                 |
| `get_diagnostics` | Exposé lorsqu'un serveur de langage est prêt. Passez des chemins ; renvoie les erreurs et avertissements. Le mode Demander peut l'utiliser                                 |
| `ask_questions`   | Questions structurées ; le tour attend jusqu'à ce que vous répondiez. Voir [Poser des questions](./ask-questions.mdx)                                                      |
| `subagent`        | Déléguer une tâche ciblée à une session enfant. Voir [Sous-agents](./subagents.mdx)                                                                                        |
| `create_plan`     | Mode Plan uniquement. Écrit `plans/{name}.md`. Voir [Modes](./modes.mdx)                                                                                                   |
| `todo_list`       | Lister les tâches à faire pour la session en cours                                                                                                                         |
| `todo_write`      | Remplacer la liste complète des tâches à faire pour la session en cours                                                                                                    |
| `finish_task`     | Exposé uniquement lorsque [Loop](./loop.mdx) est activé. Marque la tâche en cours comme terminée                                                                           |
| `dream_list`      | Lorsque [Dreams](../customize/dreams.mdx) est disponible sur Desktop, lister les résumés non expirés pour l'espace de travail et la branche actuels                        |
| `dream_read`      | Lire un Dream complet par son identifiant. Les outils d'écriture appartiennent au collecteur en arrière-plan, pas à la conversation                                        |

Les modifications et suppressions attendent [approbation](./approvals.mdx) au niveau par défaut. `shell` attend aussi.

Les serveurs [MCP](../customize/mcp.mdx) et extensions configurés ajoutent plus d'outils à la même liste.

## Outils du fournisseur [#provider-tools]

Les fournisseurs peuvent exposer leurs propres outils — recherche web, interpréteurs de code et assimilés. Les outils disponibles viennent de la déclaration du fournisseur connecté dans [config.json](../config.mdx) (écrite par l'assistant de connexion), et non d'un outil intégré à {{product.name|mdx}} : un fournisseur qui ne déclare aucun outil n'en expose aucun.

Selon la déclaration, un appel s'exécute soit dans la requête amont, soit par {{product.name|mdx}} en HTTP conformément à la déclaration, puis le résultat est réécrit comme résultat d'outil. Dans les deux cas, il s'affiche comme un appel d'outil MCP, et le runtime ne modifie jamais de lui-même les paramètres déclarés.

L'interrupteur **Outils du fournisseur** dans **Paramètres → Agents** (`agents.providerTools.enabled`, activé par défaut) les contrôle tous d'un coup. La liste par maison des outils déclarés est dans [Fournisseurs](../providers.mdx).
