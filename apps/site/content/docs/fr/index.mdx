## Fournisseurs de modèles

{{product.name|mdx}} ne fournit pas directement de services de modèles. Vous pouvez vous connecter à OpenAI, Anthropic, SpaceXAI, une passerelle ou un fournisseur régional. Chaque fournisseur fonctionne sur le même environnement : outils, approbations, sessions et comportement de l'espace de travail restent cohérents.

Les clés sont écrites dans le trousseau système sous le service `{{product.name}}`. Elles ne sont pas stockées dans `config.json`.

## Un agent, deux hôtes

Desktop et le CLI partagent un daemon local. Sessions, modèles, approbations et identifiants vivent dans le même répertoire de données, vous pouvez donc commencer une tâche dans l'application et la continuer dans le terminal.
