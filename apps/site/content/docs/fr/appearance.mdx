title: Apparence
description: Thème, polices et les dix langues de l'interface.
---

Ouvrez **Réglages → Apparence**.

## Thème

`system`, `light` ou `dark`. Stocké sous `spirit-desktop-theme`.

## Police

La police par défaut est la police système. Vous pouvez passer à une famille personnalisée.

## Langues de l'interface

L'interface Desktop / CLI propose **dix** langues. La langue par défaut est le chinois simplifié.

| Code    | Langue                |
| ------- | --------------------- |
| `zh-CN` | 简体中文 (par défaut) |
| `en`    | Anglais               |
| `zh-TW` | Chinois traditionnel  |
| `ja`    | Japonais              |
| `ko`    | Coréen                |
| `de`    | Allemand              |
| `fr`    | Français              |
| `es`    | Espagnol              |
| `pt-BR` | Portugais du Brésil   |
| `ru`    | Russe                 |

Les autres options d'apparence (mica / flou, pointeur) restent sur la même page de réglages.
