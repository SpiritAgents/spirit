Le répertoire des données utilisateur partagées dépend de la quality du build, et non du répertoire applicatif du système.

## Répertoire de données

Remplacez avec `SPIRIT_DATA_DIR`. Le serveur peut aussi utiliser `SPIRIT_SERVER_DATA_DIR` (prioritaire sur le premier).

| Build | macOS / Linux | Windows |
| --- | --- | --- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev | `~/{{product.dev.userDataFolderName}}` | `%USERPROFILE%\{{product.dev.userDataFolderName}}` |

Breaking Change : les anciens répertoires ne sont ni lus ni migrés automatiquement. Les surcharges explicites du répertoire de données restent possibles. Les caches Electron, le stockage du navigateur et l'état des fenêtres restent dans le répertoire applicatif privé de la plateforme.

Fichiers typiques :

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

Les binaires CLI utilisent SPIRIT_HOME. Sous Unix, l'installation Stable et les données partagées peuvent avoir le même répertoire parent ; bin/ et cli/ restent des fichiers d'installation. Ce réglage ne choisit pas le répertoire des données partagées.

## config.json v2

`schemaVersion` doit être `2`. La version 1 est rejetée — supprimez l'ancien fichier et [reconnectez un fournisseur](./providers.mdx).

Champs principaux :

- `providerGroups` — maisons connectées, base API, transport, modèles
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `secondaryLanguageModel`

Les clés ne sont **pas** dans ce fichier. Elles vivent dans le [trousseau](./security.mdx).

## Espace de travail `{{product.workspaceDataFolderName}}/`

| Chemin               | Rôle                                                                  |
| -------------------- | --------------------------------------------------------------------- |
| `{{product.workspaceDataFolderName}}/rule.md`    | Règle d'espace de travail [règle](./customize/rules.mdx)              |
| `{{product.workspaceDataFolderName}}/skills/`    | Compétences d'espace de travail [compétences](./customize/skills.mdx) |
| `{{product.workspaceDataFolderName}}/mcp.json`   | MCP d'espace de travail [MCP](./customize/mcp.mdx)                    |
| `{{product.workspaceDataFolderName}}/hooks.json` | Hooks d'espace de travail [hooks](./customize/hooks.mdx)              |

Également utilisés : `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## Variables d'environnement

| Variable                                                          | Rôle                                           |
| ----------------------------------------------------------------- | ---------------------------------------------- |
| `SPIRIT_DATA_DIR`                                                 | Répertoire de données                          |
| `SPIRIT_SERVER_DATA_DIR`                                          | Répertoire de données du serveur (prioritaire) |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                               |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | Programme d'installation CLI                   |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | Remplacements de processus [CLI](./cli.mdx)    |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | Hôte Web du Bureau                             |
| `SPIRIT_TERMINAL_SHELL`                                           | Shell PTY du Bureau                            |
