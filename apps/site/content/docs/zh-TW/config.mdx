共用使用者資料依建置 quality 選擇目錄，不再使用作業系統的應用程式資料目錄。

## 資料目錄

使用 `SPIRIT_DATA_DIR` 覆寫。伺服器也可以使用 `SPIRIT_SERVER_DATA_DIR`（優先於前者）。

| 建置   | macOS / Linux                             | Windows                                               |
| ------ | ----------------------------------------- | ----------------------------------------------------- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev    | `~/{{product.dev.userDataFolderName}}`    | `%USERPROFILE%\{{product.dev.userDataFolderName}}`    |

Breaking Change：不會自動讀取或遷移舊平台資料目錄；仍支援明確指定資料目錄。Electron 快取、瀏覽器儲存與視窗狀態仍保留在平台私有應用程式目錄中。

典型檔案：

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

CLI 二進位檔使用 SPIRIT_HOME。在 Unix 上，Stable 安裝與共用資料可以共用父目錄；bin/ 和 cli/ 仍屬於安裝檔案。安裝設定不決定共用資料目錄。

## config.json v2

`schemaVersion` 必須是 `2`。版本 1 會被拒絕——刪除舊檔案並[重新連線提供者](./providers.mdx)。

核心欄位：

- `providerGroups` — 已連線的家、API 基礎、傳輸、模型
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `secondaryLanguageModel`

金鑰**不**在此檔案中。它們位於[金鑰圈](./security.mdx)中。

## 工作區 `{{product.workspaceDataFolderName}}/`

| 路徑                                             | 角色                                 |
| ------------------------------------------------ | ------------------------------------ |
| `{{product.workspaceDataFolderName}}/rule.md`    | 工作區[規則](./customize/rules.mdx)  |
| `{{product.workspaceDataFolderName}}/skills/`    | 工作區[技能](./customize/skills.mdx) |
| `{{product.workspaceDataFolderName}}/mcp.json`   | 工作區 [MCP](./customize/mcp.mdx)    |
| `{{product.workspaceDataFolderName}}/hooks.json` | 工作區[鉤子](./customize/hooks.mdx)  |

也使用：`{workspace}/AGENTS.md`、`{workspace}/.agents/skills/`、`{workspace}/plans/`。

## 環境變數

| 變數                                                              | 角色                      |
| ----------------------------------------------------------------- | ------------------------- |
| `SPIRIT_DATA_DIR`                                                 | 資料目錄                  |
| `SPIRIT_SERVER_DATA_DIR`                                          | 伺服器資料目錄（優先）    |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)          |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | CLI 安裝程式              |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | [CLI](./cli.mdx) 程序覆寫 |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | 桌面網頁主機              |
| `SPIRIT_TERMINAL_SHELL`                                           | 桌面 PTY Shell            |
