---
title: 子智慧體
description: 將一個有範圍的任務委派給子會話，可選擇在 git worktree 中進行。
---

智慧體可以呼叫 `subagent` 來啟動子會話。子智慧體處理隔離的任務，並僅將最終結果回傳給父智慧體。

## 參數

| 欄位               | 必填 | 角色                                    |
| ------------------ | ---- | --------------------------------------- |
| `task`             | 是   | 子智慧體應該做什麼                      |
| `success_criteria` | 否   | 子智慧體如何知道任務已完成              |
| `context_summary`  | 否   | 簡短的背景資訊，子智慧體不必重新探索    |
| `files_to_inspect` | 否   | 優先閱讀的路徑                          |
| `expected_output`  | 否   | 父智慧體期望回傳的結果格式              |
| `worktree`         | 否   | `true` 表示在隔離的 git worktree 中編輯 |

當子智慧體會編輯檔案，且其他子智慧體可能同時編輯時，請使用 `worktree: true`。若為唯讀工作，則省略該參數。

## 限制

已在 worktree 中執行的子智慧體無法再啟動另一個 worktree。會話開始和結束時可以執行 hooks（`subagentStart` / `subagentEnd`）。您可以從 Desktop 的子智慧體檢視器或 CLI TUI 的 `/subagent` 檢視子會話。
