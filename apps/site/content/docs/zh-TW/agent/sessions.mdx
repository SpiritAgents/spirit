每次對話都是一個工作階段。工作階段儲存在 {{product.name|mdx}} 資料目錄（`chats/`）下，並在側邊欄中按工作區分組顯示。

## 倒帶

倒帶使用者訊息可將對話還原至該時間點，如有需要可編輯提示詞，然後重新傳送。當上一輪走向錯誤，且你寧可重試也不願累積修正時，可以使用此功能。

## 分支

從助理訊息進行分支，可以岔出新的對話。Desktop 也可分支至側邊聊天，讓原始對話保持原樣。

## Worktree

Composer 的 **工作位置** 可以是 `local`（你開啟的工作區）或 `worktree`（隔離的 git worktree）。子智慧體可設定 `worktree: true` 以獲得相同的隔離效果。

Worktree 路徑看起來像 `{repoRoot}.worktrees/spirit-*`。已在 worktree 內運行的子智慧體無法再從該處啟動另一個 worktree。

Worktree 適用於平行編輯，避免互相衝突。它們並非工作階段的備份——倒帶與分支負責處理對話歷史。
