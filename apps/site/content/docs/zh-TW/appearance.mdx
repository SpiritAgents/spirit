---
title: 外觀
description: 主題、字型與十種介面語言。
---

開啟**設定 → 外觀**。

## 主題

`system`、`light` 或 `dark`。儲存為 `spirit-desktop-theme`。

## 字型

預設為系統字型。您可以切換至自訂字型家族。

## 介面語言

Desktop / CLI 介面有**十種**語言。預設為簡體中文。

| 代碼    | 語言                |
| ------- | ------------------- |
| `zh-CN` | 简体中文 (預設)     |
| `en`    | English             |
| `zh-TW` | 繁體中文            |
| `ja`    | 日本語              |
| `ko`    | 한국어              |
| `de`    | Deutsch             |
| `fr`    | Français            |
| `es`    | Español             |
| `pt-BR` | Português do Brasil |
| `ru`    | Русский             |

其他外觀切換（mica / blur、指標）仍位於相同的設定頁面。
