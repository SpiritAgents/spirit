規則是以 Markdown 撰寫，Agent 會隨時參考。共有三個位置：

| 範圍               | 路徑                          |
| ------------------ | ----------------------------- |
| 工作區 Agents 檔案 | `{workspace}/AGENTS.md`       |
| 工作區 Spirit 規則 | `{workspace}/.spirit/rule.md` |
| 使用者規則         | `{spiritDataDir}/rule.md`     |

在 `AGENTS.md` 中撰寫專案慣例，以便任何開啟儲存庫的人都能看到。使用 `.spirit/rule.md` 存放 Spirit 特有的註記，這些註記您不會放入通用的 agents 檔案中。使用使用者規則來記錄您跨工作區的偏好設定。

在**設定 → 規則**中管理位置。內建的 Skill 與 `create-rule` 可以為您草擬規則檔案。[擴充功能](../develop/extensions.mdx) 捆綁的 rule 只在該擴充功能啟用時生效，不會出現在此設定清單。
