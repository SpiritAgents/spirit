---
title: 整合
description: GitHub 裝置登入。Token 會存放在鑰匙圈中。
---

**設定 → 整合** 透過 OAuth 裝置流程連接 GitHub。您在瀏覽器中核准；{{product.name|mdx}} 將 token 儲存在系統鑰匙圈的 `{{product.name}}` 服務下。

完整的控制面板可在 Electron 應用程式中使用。其他 shell 可能只顯示有限的提示。

在 [自動化](./automations.mdx) 能針對 pull request 或問題觸發之前，需要先連接 GitHub。中斷 GitHub 會移除該觸發路徑；現有的時間自動化會繼續執行。
