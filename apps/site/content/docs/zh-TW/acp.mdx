ACP（Agent 用戶端協定）以 `spirit-acp`（`@spiritagent/acp-server`）實作。它使用 stdio ndJSON，與 Desktop 和 CLI 共用相同的資料目錄和金鑰環，並可執行 `--setup` 以連接提供者。

**公開下載頁面尚未列出 ACP。** {{product.name|mdx}} 仍在準備將其列入 ACP 註冊表。

## 在列出之前的臨時設定

在列出之前，請使用 `npx` 安裝並完成設定：

```bash
npx @spiritagent/acp-server --setup
```

或將 ACP 用戶端（例如 Zed）指向 stdio 入口：

```json
"agent_servers": {
  "{{product.name}}": {
    "command": "node",
    "args": ["path/to/packages/acp-server/dist/src/stdio-entry.js"]
  }
}
```

使用**在終端機中執行**進行驗證，完成 `--setup`，然後執行 `authenticate` 和 `session/new`。

| 變數                   | 角色                                                   |
| ---------------------- | ------------------------------------------------------ |
| `SPIRIT_ACP_WORKSPACE` | 工作區根目錄（預設為用戶端 cwd）                       |
| `SPIRIT_ACP_DATA_DIR`  | 資料目錄；否則使用 `SPIRIT_DATA_DIR`，再使用平台預設值 |
