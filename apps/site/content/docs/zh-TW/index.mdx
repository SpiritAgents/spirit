## 模型提供者

{{product.name|mdx}} 不直接提供模型服務。您可以連接 OpenAI、Anthropic、SpaceXAI、閘道或區域提供者。每個提供者都在相同的框架上執行：工具、核准、工作階段和工作區行為保持一致。

金鑰寫入系統鑰匙圈，服務名稱為 `{{product.name}}`。它們不會儲存在 `config.json` 中。

## 一個智慧體，兩個主機

Desktop 和 CLI 共用一個本機 daemon。工作階段、模型、核准和憑證都位於相同的資料目錄中，因此您可以在應用程式中開始任務，並在終端機中繼續。

2. 開啟工作區
3. 連接一個提供者
4. 要求智慧體閱讀儲存庫、進行小修改，並核准變更
