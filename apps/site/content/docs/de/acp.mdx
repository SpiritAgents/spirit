ACP (Agent Client Protocol) ist als `spirit-acp` (`@spiritagent/acp-server`) implementiert. Es spricht stdio ndJSON, teilt dasselbe Datenverzeichnis und denselben Schlüsselbund wie Desktop und CLI und kann `--setup` ausführen, um einen Provider zu verbinden.

**Die öffentliche Download-Seite listet ACP noch nicht.** {{product.name|mdx}} bereitet sich noch darauf vor, es im ACP-Registry zu listen.

## Vorübergehende Einrichtung vor dem Listing

Bis es gelistet ist, installieren und Einrichtung mit `npx` abschließen:

```bash
npx @spiritagent/acp-server --setup
```

Oder einen ACP-Client (zum Beispiel Zed) auf den stdio-Eintrag verweisen:

```json
"agent_servers": {
  "{{product.name}}": {
    "command": "node",
    "args": ["path/to/packages/acp-server/dist/src/stdio-entry.js"]
  }
}
```

Mit **Run in terminal** authentifizieren, `--setup` abschließen, dann `authenticate` und `session/new`.

| Variable               | Rolle                                                                  |
| ---------------------- | ---------------------------------------------------------------------- |
| `SPIRIT_ACP_WORKSPACE` | Workspace-Root (Standard: das cwd des Clients)                         |
| `SPIRIT_ACP_DATA_DIR`  | Datenverzeichnis; sonst `SPIRIT_DATA_DIR`, dann die Plattform-Standard |
