---
title: CLI installieren
description: Installieren Sie die Spirit CLI mit dem Installationsskript, SPIRIT_HOME und SPIRIT_VERSION.
---

Die CLI ist ein Terminal-Host mit einer TUI und einem nicht-interaktiven `-p`-Modus. Sie kommuniziert mit demselben lokalen Daemon wie [Desktop](./desktop.mdx).

## Installationsskript

macOS und Linux:

```bash
curl -fsSL https://spirit.dev/install | bash
```

Windows (PowerShell):

```powershell
irm https://spirit.dev/install.ps1 | iex
```

Das Skript lädt einen Build von `download.spirit.dev` herunter, prüft dessen SHA-256 gegen die `SHA256SUMS.txt` des passenden GitHub-Release (Abbruch bei Abweichung), entpackt ihn und fügt `spirit` zu Ihrem `PATH` hinzu.

Öffnen Sie ein neues Terminal und dann:

```bash
spirit --version
```

## Wohin es installiert wird

Das Installationsverzeichnis ist **nicht** das Spirit-Datenverzeichnis.

|                                                    | Standard                                                                                                     | Überschreiben     |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------- |
| CLI-Binärdateien                                   | Unix: `~/.spirit` · Windows: `%LOCALAPPDATA%\Spirit`                                                         | `SPIRIT_HOME`     |
| Sitzungen, Konfiguration, Schlüsselbund-Referenzen | macOS: `~/Library/Application Support/Spirit` · Windows: `%APPDATA%\Spirit` · Linux: `~/.local/share/Spirit` | `SPIRIT_DATA_DIR` |

Auf Unix verlinkt das Skript `$SPIRIT_HOME/bin/spirit` → `$SPIRIT_HOME/cli/current/bin/spirit` und fügt `export PATH="$SPIRIT_HOME/bin:$PATH"` zu `~/.profile`, `~/.bashrc` und `~/.zshrc` hinzu (Markierung `# spirit cli`).

## Version oder Spiegel festlegen

| Variable               | Standard                                 | Rolle                                         |
| ---------------------- | ---------------------------------------- | --------------------------------------------- |
| `SPIRIT_HOME`          | `~/.spirit` oder `%LOCALAPPDATA%\Spirit` | Installationsverzeichnis für CLI-Binärdateien |
| `SPIRIT_VERSION`       | `latest`                                 | Versionssegment in der Download-URL           |
| `SPIRIT_DOWNLOAD_HOST` | `download.spirit.dev`                   | CDN-Host                                      |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL https://spirit.dev/install | bash
```

Sie können auch ein CLI-Archiv von der [Download-Seite](/en-US/download) oder [GitHub Releases](https://github.com/SpiritAgents/spirit/releases/latest) herunterladen und selbst entpacken.

## Erster Start

```bash
cd /path/to/your/project
spirit
```

Das öffnet die TUI. Fügen Sie einen Anbieter mit `/model add` hinzu oder von der Shell aus mit `spirit model add`. Siehe [Schnellstart](../quickstart.mdx).
