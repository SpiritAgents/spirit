Die CLI ist ein Terminal-Host mit einer TUI und einem nicht-interaktiven `-p`-Modus. Sie kommuniziert mit demselben lokalen Daemon wie [Desktop](./desktop.mdx).

## Installationsskript

macOS und Linux:

```bash
curl -fsSL {{product.websiteOrigin}}/install | bash
```

Windows (PowerShell):

```powershell
irm {{product.websiteOrigin}}/install.ps1 | iex
```

Das Skript lädt einen Build von `{{product.downloadOrigin|host}}` herunter, prüft dessen SHA-256 gegen die `SHA256SUMS.txt` des passenden GitHub-Release (Abbruch bei Abweichung), entpackt ihn und fügt `spirit` zu Ihrem `PATH` hinzu.

Öffnen Sie ein neues Terminal und dann:

```bash
spirit --version
```

## Wohin es installiert wird

CLI-Binärdateien verwenden SPIRIT_HOME. Unter Unix können Stable-Installation und gemeinsame Daten dasselbe übergeordnete Verzeichnis nutzen; bin/ und cli/ bleiben Installationsdateien. Die Installationseinstellung bestimmt nicht das gemeinsame Datenverzeichnis.

|                                                    | Standard                                                                                                                                                                                                              | Überschreiben     |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| CLI-Binärdateien                                   | Unix: `~/.spirit` · Windows: `%LOCALAPPDATA%\Spirit`                                                                                                                                                                  | `SPIRIT_HOME`     |
| Sitzungen, Konfiguration, Schlüsselbund-Referenzen | Stable: `~/{{product.stable.userDataFolderName}}` · Dev: `~/{{product.dev.userDataFolderName}}` · Windows: `%USERPROFILE%\{{product.stable.userDataFolderName}}` / `%USERPROFILE%\{{product.dev.userDataFolderName}}` | `SPIRIT_DATA_DIR` |

Auf Unix verlinkt das Skript `$SPIRIT_HOME/bin/spirit` → `$SPIRIT_HOME/cli/current/bin/spirit` und fügt `export PATH="$SPIRIT_HOME/bin:$PATH"` zu `~/.profile`, `~/.bashrc` und `~/.zshrc` hinzu (Markierung `# spirit cli`).

## Version oder Spiegel festlegen

| Variable               | Standard                                 | Rolle                                         |
| ---------------------- | ---------------------------------------- | --------------------------------------------- | -------- |
| `SPIRIT_HOME`          | `~/.spirit` oder `%LOCALAPPDATA%\Spirit` | Installationsverzeichnis für CLI-Binärdateien |
| `SPIRIT_VERSION`       | `latest`                                 | Versionssegment in der Download-URL           |
| `SPIRIT_DOWNLOAD_HOST` | `{{product.downloadOrigin|host}}`                                       | CDN-Host |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL {{product.websiteOrigin}}/install | bash
```

Sie können auch ein CLI-Archiv von der [Download-Seite](/en-US/download) oder [GitHub Releases](https://github.com/SpiritAgents/spirit/releases/latest) herunterladen und selbst entpacken.

## Erster Start

```bash
cd /path/to/your/project
spirit
```

Das öffnet die TUI. Fügen Sie einen Anbieter mit `/model add` hinzu oder von der Shell aus mit `spirit model add`. Siehe [Schnellstart](../quickstart.mdx).
