### Shell

Desktop (nur Electron) hat einen **Shell**-Tab mit einem eingebetteten PTY. Dieses Bedienfeld ist für dich. Der Agent verwendet weiterhin [`shell`](./agent/tools.mdx) und Genehmigung; er tippt nicht in dein PTY.

CLI hat kein eingebettetes PTY-Bedienfeld. Befehle laufen weiterhin über dasselbe `shell`-Tool auf dem gemeinsamen Daemon.

Überschreibe die Desktop-PTY-Shell mit `SPIRIT_TERMINAL_SHELL`, falls du ein bestimmtes Binär benötigst.

### Git

Der **Git**-Tab zeigt Änderungen und Verlauf. Chips im Composer können **Commit**, **Push** oder **Merge** starten. Dies ist Host-UI, kein Skill-Paket.

Diese Chips injizieren einen festen Prompt. Der Agent verwendet dann [Workspace- und `shell`-Tools](./agent/tools.mdx).

### LSP

Aktiviere Sprachserver in **Settings → Agents** und installiere dann einen Anbieter, falls er fehlt. Sobald ein Server bereit ist, kann der Agent [`get_diagnostics`](./agent/tools.mdx) aufrufen.

| ID              | Sprachen | Installationsmethode                        |
| --------------- | -------- | ------------------------------------------- |
| `pyright`       | Python   | npm (`pyright`)                             |
| `gopls`         | Go       | Go-Toolchain                                |
| `rust-analyzer` | Rust     | rustup                                      |
| `clangd`        | C, C++   | Plattformpaket (z. B. Homebrew oder winget) |
| `jdtls`         | Java     | Manuell                                     |
| `omnisharp`     | C#       | .NET                                        |

clangd und jdtls sind nicht gebündelt. Installiere sie selbst und kehre dann zu Settings → Agents zurück.

### Tab

Tab ist Monaco-Inline-Vervollständigung. Akzeptiere Geistertext mit einer Tab-Taste. Öffne **Settings → Tab**, aktiviere Code-Vervollständigung (`codeCompletionEnabled`) und weise ein leichtgewichtiges Chat-Modell in **Settings → Models** zu. Dieser Slot dient auch anderen leichtgewichtigen Hintergrundaufgaben.

Wenn die Vervollständigung leer ist, überprüfen Sie, ob ein leichtgewichtiges Chat-Modell verbunden ist und die Einstellung aktiviert ist. Dies ist nicht die Agent-Konversation.

## Web-Host-Kopplung

Desktop kann einen Web-Client auf dem lokalen Rechner bereitstellen.

- Standard-Listenadresse: `127.0.0.1:7788`
- Einstellungen → **Netzwerk** → Web-Remotezugriff
- Beim ersten Besuch wird ein **6-stelliger Kopplungscode** von dieser Einstellungsseite angefordert
- Fünf fehlgeschlagene Versuche sperren die Kopplung, bis Sie den Web-Host neu starten.
- Das Token wird im Browser als `spirit-web-host-token` gespeichert

Der Agent läuft weiterhin im gemeinsamen Daemon. Der Web-Client empfängt einen authentifizierten Snapshot; es ist kein zweiter Agent.

**Das Binden von `0.0.0.0` für den Fernzugriff im LAN ist kein offizieller Produktpfad.** Daemon und Web-Host bleiben standardmäßig auf Loopback. Eine LAN-IPv4-Listenadresse im Netzwerk ist für einen Rechner, den Sie kontrollieren, nicht für einen öffentlichen Server gedacht.

Entwicklungs-Overrides: `SPIRIT_DESKTOP_WEB_HOST=1`, `SPIRIT_WEB_HOST`, `SPIRIT_WEB_PORT`.
