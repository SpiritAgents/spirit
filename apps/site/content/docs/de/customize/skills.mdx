Ein Skill ist ein Ordner mit einer `SKILL.md`. Spirit entdeckt Skills an drei Orten:

| Bereich          | Pfad                                         |
| ---------------- | -------------------------------------------- |
| Benutzer         | `{spiritDataDir}/skills/{name}/SKILL.md`     |
| Workspace Spirit | `{workspace}/.spirit/skills/{name}/SKILL.md` |
| Workspace agents | `{workspace}/.agents/skills/{name}/SKILL.md` |

Wenn Sie einen Skill in einer Runde erwähnen, kann Spirit dessen vollständigen Text an diese Benutzernachricht anhängen. Es fügt nicht jeden Skill in das Systemprompt ein.

## Frontmatter

`SKILL.md` muss mit Frontmatter beginnen. Eine Datei ohne `name` oder `description` wird nicht entdeckt.

| Feld          | Beschreibung                                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `name`        | Erforderlich. Skill-Name; muss mit dem Ordnernamen übereinstimmen. 1–64 Zeichen, nur Kleinbuchstaben, Ziffern und Bindestriche |
| `description` | Erforderlich. Kurze Beschreibung                                                                                               |

## Integrierte Skills

Diese sind in Spirit enthalten (sie sind keine Dateien in Ihrem Datenspeicher):

- `create-rule` — eine [Regel](./rules.mdx) entwerfen
- `create-skill` — einen [Skill](./skills.mdx) entwerfen
- `create-hook` — einen [Hook](./hooks.mdx) entwerfen
- `create-extension` — eine [Erweiterung](../develop/extensions.mdx) entwerfen

Verwalten Sie Skills in **Einstellungen → Skills**. Git-Commit-/Push-/Merge-Chips sind Host-UI, nicht gebündelte Skills. Siehe [Desktop](../desktop.mdx). In einer [Erweiterung](../develop/extensions.mdx) gebündelte Skills sind verfügbar, wenn die Erweiterung aktiviert ist. Sie erscheinen nicht in dieser Einstellliste.
