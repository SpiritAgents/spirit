---
title: Integrationen
description: GitHub-Geräteanmeldung. Der Token wird im Schlüsselbund gespeichert.
---

**Einstellungen → Integrationen** verbindet GitHub mit dem OAuth-Gerätefluss. Sie genehmigen im Browser; {{product.name|mdx}} speichert den Token im System-Schlüsselbund unter dem Dienst `{{product.name}}`.

Das vollständige Bedienfeld ist in der Electron-App verfügbar. Andere Shells zeigen möglicherweise einen eingeschränkten Hinweis.

GitHub ist erforderlich, bevor [Automationen](./automations.mdx) bei Pull-Requests oder Issues ausgelöst werden können. Das Trennen von GitHub entfernt diesen Auslöserpfad; bestehende Zeitautomationen laufen weiter.
