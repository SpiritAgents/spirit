Regeln sind Markdown, die der Agent immer berücksichtigt. Es gibt drei Slots:

| Geltungsbereich          | Pfad                      |
| ------------------------ | ------------------------- | --------------------------------------------------------- |
| Workspace-Agents-Datei   | `{workspace}/AGENTS.md`   |
| Workspace-{{product.name|mdx}}-Regel               | `{workspace}/{{product.workspaceDataFolderName}}/rule.md` |
| Benutzerregel            | `{spiritDataDir}/rule.md` |

Schreiben Sie Projektkonventionen in `AGENTS.md`, damit jeder, der das Repo öffnet, sie sieht. Verwenden Sie `{{product.workspaceDataFolderName}}/rule.md` für {{product.name|mdx}}-spezifische Hinweise, die Sie nicht in die generische Agents-Datei aufnehmen möchten. Verwenden Sie die Benutzerregel für Einstellungen, die Ihnen über alle Workspaces hinweg folgen.

Verwalten Sie Slots unter **Einstellungen → Regeln**. Eine integrierte Skill, `create-rule`, kann eine Regeldatei für Sie entwerfen. Eine in einer [Erweiterung](../develop/extensions.mdx) gebündelte Rule gilt nur, wenn die Erweiterung aktiviert ist. Sie erscheint nicht in dieser Einstellliste.
