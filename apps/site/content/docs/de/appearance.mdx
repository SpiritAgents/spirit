description: Design, Schriftarten und die zehn UI-Sprachen.
---

Öffnen Sie **Einstellungen → Darstellung**.

## Design

`system`, `light`, oder `dark`. Gespeichert als `spirit-desktop-theme`.

## Schriftart

Standard ist die Systemschriftart. Sie können zu einer benutzerdefinierten Schriftfamilie wechseln.

## UI-Sprachen

Die Desktop-/CLI-Benutzeroberfläche hat **zehn** Sprachen. Standard ist vereinfachtes Chinesisch.

| Code    | Sprache                       |
| ------- | ----------------------------- |
| `zh-CN` | 简体中文 (Standard)           |
| `en`    | Englisch                      |
| `zh-TW` | 繁體中文                      |
| `ja`    | Japanisch                     |
| `ko`    | Koreanisch                    |
| `de`    | Deutsch                       |
| `fr`    | Französisch                   |
| `es`    | Spanisch                      |
| `pt-BR` | Brasilianisches Portugiesisch |
| `ru`    | Russisch                      |

Andere Darstellungsoptionen (Mica / Unschärfe, Zeiger) bleiben auf derselben Einstellungsseite.
