---
title: Subagents
description: Delegieren Sie eine abgegrenzte Aufgabe an eine untergeordnete Sitzung, optional in einem git Worktree.
---

Der Agent kann `subagent` aufrufen, um eine untergeordnete Sitzung zu starten. Das Kind arbeitet an einer isolierten Aufgabe und gibt nur sein endgültiges Ergebnis an das Elternteil zurück.

## Argumente

| Feld               | Erforderlich | Rolle                                                       |
| ------------------ | ------------ | ----------------------------------------------------------- |
| `task`             | ja           | Was das Kind tun soll                                       |
| `success_criteria` | nein         | Woran das Kind erkennt, dass es fertig ist                  |
| `context_summary`  | nein         | Kurzer Hintergrund, den das Kind nicht neu entdecken muss   |
| `files_to_inspect` | nein         | Pfade, die zuerst gelesen werden sollen                     |
| `expected_output`  | nein         | Form des Ergebnisses, das das Elternteil zurückhaben möchte |
| `worktree`         | nein         | `true`, um in einem isolierten git Worktree zu bearbeiten   |

Verwenden Sie `worktree: true`, wenn das Kind Dateien bearbeitet und andere Kinder gleichzeitig bearbeiten können. Lassen Sie es für reine Lesevorgänge weg.

## Grenzen

Ein Kind, das bereits in einem Worktree läuft, kann keinen weiteren Worktree starten. Sitzungsstart und -ende können Hooks ausführen (`subagentStart` / `subagentEnd`). Sie können untergeordnete Sitzungen im Subagent-Viewer auf Desktop oder über `/subagent` in der CLI TUI einsehen.
