## Modellanbieter

{{product.name|mdx}} bietet keine Modelldienste direkt an. Sie können OpenAI, Anthropic, SpaceXAI, ein Gateway oder einen regionalen Anbieter verbinden. Jeder Anbieter läuft auf derselben Plattform: Tools, Genehmigungen, Sitzungen und Workspace-Verhalten bleiben konsistent.

Schlüssel werden im System-Schlüsselbund unter dem Dienst `{{product.name}}` gespeichert. Sie werden nicht in `config.json` abgelegt.

## Ein Agent, zwei Hosts

Desktop und CLI teilen sich einen lokalen Daemon. Sitzungen, Modelle, Genehmigungen und Anmeldeinformationen befinden sich im selben Datenverzeichnis, sodass Sie eine Aufgabe in der App starten und im Terminal fortsetzen können.

## Hier starten

1. [Desktop oder CLI installieren](./quickstart.mdx)
2. Einen Workspace öffnen
3. Einen Anbieter verbinden
4. Den Agenten bitten, das Repository zu lesen, eine kleine Änderung vorzunehmen und die Änderung zu genehmigen
