---
title: 外観
description: テーマ、フォント、および10のUI言語。
---

**設定 → 外観**を開きます。

## テーマ

`system`、`light`、`dark`。`spirit-desktop-theme`として保存されます。

## フォント

デフォルトはシステムフォントです。カスタムファミリーに切り替えることができます。

## UI言語

Desktop / CLI UIには**10**の言語があります。デフォルトは簡体字中国語です。

| コード  | 言語                  |
| ------- | --------------------- |
| `zh-CN` | 简体中文 (デフォルト) |
| `en`    | 英語                  |
| `zh-TW` | 繁體中文              |
| `ja`    | 日本語                |
| `ko`    | 韓国語                |
| `de`    | ドイツ語              |
| `fr`    | フランス語            |
| `es`    | スペイン語            |
| `pt-BR` | ブラジルポルトガル語  |
| `ru`    | ロシア語              |

その他の外観トグル（mica / blur、ポインター）は同じ設定ページにあります。
