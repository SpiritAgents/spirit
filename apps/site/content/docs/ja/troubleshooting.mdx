## config.json が拒否される

ファイルは `schemaVersion: 1` である必要があります。それ以外のバージョンはすべて拒否されます。古いファイルを削除し、[プロバイダーを再接続](./providers.mdx)してください。平文の `apiKey` を宣言していない限り、キーはそのファイルにはなく、[キーリング](./security.mdx)にあります。

## CLI はインストール済みだが、設定が空

`SPIRIT_HOME` (`~/.spirit`) にバイナリをインストールしましたね。セッションと `config.json` は[データディレクトリ](./config.mdx)にあります。上書きした場合は `SPIRIT_DATA_DIR` を確認してください。

## `spirit -p` が失敗しました

- 承認が必要 → `-a auto-approval` / `-a bypass-approval` を使用するか、TUI を使用してください
- [ask_questions](./agent/ask-questions.mdx) が必要 → TUI を使用するか、プロンプトを決定的にしてください
- タイムアウト → ヘッドレスは 30 分で停止します

## モデルがインポートされない

そのハウスの[プロバイダーページ](./providers.mdx)を開いてください。サイト、プランのエンドポイント、Azure リソース、Cloudflare アカウント、Bedrock のリージョン / IAM、または Vertex のプロジェクト / ロケーションを確認してください。TokenHub は Chat Completions に留まります。Bedrock Bearer はモデルを一覧表示できません。

## キーがキーリングにない

**設定 → モデル** で再接続するか、`spirit model add` を実行してください。ウィザードは `config.json` の**前に**キーリングを書き込みます。リポジトリにキーを貼り付けないでください。

## Web Host のペアリングに失敗しました

コードが間違っている場合は、もう一度試してください。5 回失敗すると、**設定 → ネットワーク** で Web Host を再起動するまでペアリングがロックされます（`PAIRING_LOCKED`）。ホストはペアリングをサポートしている必要があります。一般的な Web プレビューではサポートされていない場合があります。

## LSP がない

サーバーを自分でインストールして（clangd は Homebrew / winget で、jdtls は手動で）、**設定 → エージェント** で有効にしてください。[Desktop](./desktop.mdx) を参照してください。

## Tab 補完が空

**設定 → Tab** を有効にして、セカンダリ言語モデルを割り当ててください。[Desktop](./desktop.mdx) を参照してください。

## ACP がダウンロードページにない

それは想定内です。ACP は実装されていますが、ダウンロード列はまだプレースホルダーです。[ACP](./acp.mdx) を参照してください。
