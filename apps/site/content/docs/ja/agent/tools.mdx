---
title: ツール
description: エージェントが呼び出せるツール。一部はモデル、スロット、またはモードが条件を満たす場合にのみ表示されます。
---

これらのツールは、開いているワークスペースに対して動作します。Askモードは読み取りと検索ができますが、作成、編集、削除、パッチ適用、`shell`の実行、画像や動画の生成はできません。

| ツール            | 役割                                                                                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `read_file`       | ファイルの読み取り、または画像や動画の読み取り                                                                                                         |
| `create_file`     | ファイルの作成                                                                                                                                         |
| `edit_file`       | 既存ファイルの編集                                                                                                                                     |
| `delete_file`     | ファイルの削除                                                                                                                                         |
| `apply_patch`     | モデルとトランスポートが適格な場合に公開（例：OpenAIプロバイダーのGPTモデル）。そのパスでは`create_file` / `edit_file` / `delete_file`を置き換えます。 |
| `glob`            | グロブによるパスの検索（`.gitignore`を尊重）                                                                                                           |
| `grep`            | ファイル内容の検索（`.gitignore`を尊重）                                                                                                               |
| `ls`              | 1つのディレクトリを再帰なしで一覧表示。パスは絶対パスである必要があります。                                                                            |
| `shell`           | `reason`と`command`を使用してコマンドを実行。Askモードでは呼び出せません。                                                                             |
| `web_fetch`       | `http`または`https`のURLを取得してMarkdownを返します。ホストツールであり、プロバイダーの検索ではありません。                                           |
| `generate_image`  | **設定 → モデル**で画像モデルを割り当てた後に公開されます。画像を1枚生成します。Askモードでは呼び出せません。                                          |
| `generate_video`  | **設定 → モデル**で動画モデルを割り当てた後に公開されます。短い動画を生成します。Askモードでは呼び出せません。                                         |
| `get_diagnostics` | 言語サーバーが準備完了のときに公開されます。パスを渡すとエラーと警告を返します。Askモードでも使用できます。                                            |
| `ask_questions`   | 構造化された質問。回答があるまでターンは待機します。[質問する](./ask-questions.mdx)を参照してください。                                                |
| `subagent`        | スコープされたタスクを子セッションに委任します。[サブエージェント](./subagents.mdx)を参照してください。                                                |
| `create_plan`     | プランモードのみ。`plans/{name}.md`を書き込みます。[モード](./modes.mdx)を参照してください。                                                           |
| `todo_list`       | 現在のセッションのTODOを一覧表示します。                                                                                                               |
| `todo_write`      | 現在のセッションのTODOリスト全体を置き換えます。                                                                                                       |
| `finish_task`     | [ループ](./loop.mdx)がオンのときのみ公開されます。現在のタスクを完了としてマークします。                                                               |
| `dream_list`      | [Dreams](../customize/dreams.mdx)がデスクトップで利用可能な場合、現在のワークスペースとブランチの有効期限が切れていないサマリーを一覧表示します。      |
| `dream_read`      | IDで完全なドリームを1つ読み取ります。書き込みツールは会話ではなくバックグラウンドコレクターに属します。                                                |

編集と削除は、デフォルトレベルで[承認](./approvals.mdx)を待ちます。`shell`も待機します。

構成された[MCP](../customize/mcp.mdx)サーバーと拡張機能は、同じリストにさらにツールを追加します。

## プロバイダーツール [#provider-tools]

プロバイダーは独自のツール（ウェブ検索、コードインタープリターなど）を公開できます。どのツールが存在するかは、接続済みプロバイダーが [config.json](../config.mdx) で宣言する内容（接続ウィザードが書き込みます）によって決まり、{{product.name|mdx}} の組み込みツールではありません。ツールを宣言していないプロバイダーは、何も公開しません。

宣言に応じて、呼び出しはアップストリームのリクエスト内で実行されるか、{{product.name|mdx}} が宣言どおりに HTTP で実行してツール結果として書き戻されます。どちらの形態も MCP ツール呼び出しと同じように表示され、ランタイムが宣言されたパラメーターを勝手に変更することはありません。

**設定 → エージェント** の **プロバイダーツール** トグル（`agents.providerTools.enabled`、デフォルトはオン）がこれらすべてを一括で制御します。プロバイダーごとの宣言済みツールの一覧は [プロバイダー](../providers.mdx) を参照してください。
