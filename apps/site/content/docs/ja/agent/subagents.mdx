---
title: サブエージェント
description: スコープを限定したタスクを子セッションに委任します。必要に応じてgitワークツリーで実行します。
---

エージェントは `subagent` を呼び出して子セッションを開始できます。子は独立したタスクに取り組み、最終結果のみを親に返します。

## 引数

| フィールド         | 必須   | 役割                                                   |
| ------------------ | ------ | ------------------------------------------------------ |
| `task`             | はい   | 子が行うべき内容                                       |
| `success_criteria` | いいえ | 子が完了を判断するための条件                           |
| `context_summary`  | いいえ | 子が再発見する必要のない短い背景情報                   |
| `files_to_inspect` | いいえ | 最初に読むべきパス                                     |
| `expected_output`  | いいえ | 親が返してほしい結果の形                               |
| `worktree`         | いいえ | `true` の場合は、隔離されたgitワークツリーで編集します |

子がファイルを編集し、他の子も同時に編集する可能性がある場合は、`worktree: true` を使用します。読み取り専用の作業では省略します。

## 制限

ワークツリー内で既に実行中の子は、別のワークツリーを開始できません。セッションの開始と終了にフック（`subagentStart` / `subagentEnd`）を実行できます。DesktopのサブエージェントビューアまたはCLI TUIの`/subagent`から子セッションを検査できます。
