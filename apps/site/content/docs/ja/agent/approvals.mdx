---
title: 承認
description: デフォルト、自動承認、バイパス承認。各レベルがまだ停止するもの。
---

すべてのリスクのあるツール呼び出しはあなたを待つことができます。{{product.name|mdx}} には3つの承認レベルがあります。Desktop では **デフォルト承認**、**自動承認**、**バイパス承認** として表示されます。CLI では `/approval` または `-a` を使用します。

| レベル         | ID                | 動作                                                                                                                                 |
| -------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| デフォルト承認 | `default`         | ファイル編集、シェル、その他の高リスクツールは自分で承認します。                                                                     |
| 自動承認       | `auto-approval`   | セカンダリ言語モデルが高リスクな呼び出しをレビューします。そのレビュー（またはフック）が要求しない限り、プロンプトは表示されません。 |
| バイパス承認   | `bypass-approval` | 高リスクツールは承認プロンプトなしで実行されます。                                                                                   |

## バイパスがスキップしないもの

`bypass-approval` でも以下は停止します：

- [ask_questions](./ask-questions.mdx)
- 質問が必要な拡張機能フロー
- `preToolUse` で `ask` を返すフック

自動承認もフックの `ask` を上書きできません。

## どれを使うべきか

エージェントがいくつか良い編集を行うのを見るまで **デフォルト** のままにしてください。スピードが欲しいが、それでも二重チェックが必要な場合は **自動承認** を使用してください。**バイパス** は、捨てるブランチまたは監視しているタスクでのみ使用してください。

ヘッドレス `spirit -p` は、呼び出しが承認を必要とする場合に失敗します。`-a auto-approval` または `-a bypass-approval` を渡すか、TUI を使用してください。
