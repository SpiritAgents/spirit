---
title: 拡張機能
description: マーケットプレイスから拡張機能をインストールし、ZIP パッケージをインポートし、独自のリモート拡張機能マーケットプレイスを追加できます。
---

拡張機能は Spirit に能力を追加します——ツール、スキル、フック、MCP サーバー、UI 貢献。拡張機能は拡張機能マーケットプレイスを通じて配布されます：

- **組み込み**——アプリに同梱。
- **個人**——自分で追加した ZIP パッケージのインポート。
- **リモート拡張機能マーケットプレイス**——自分で追加するもの：Git リポジトリ、HTTP インデックス URL、ローカルディレクトリ。

Desktop では、サイドバーの**拡張機能**ページにマーケットプレイスごとのタブが表示され、**すべて**タブは全マーケットプレイスを 1 つのリストに統合します。CLI では `spirit extension` コマンドと `/extension marketplace` TUI で同じフローを利用できます。

## インストール、更新、アンインストール

Desktop では、**拡張機能**を開き、拡張機能を選んで**インストール**を選択します。インストール済みの拡張機能には**その他の操作**メニューが表示され、**無効にする**（削除せずにオフにする）と**アンインストール**を選べます。マーケットプレイスが新しいバージョンを公開すると、詳細ページに**更新**ボタンが表示されます。

CLI の場合：

```bash
spirit extension list
spirit extension install <name>
spirit extension update <name>
spirit extension remove <id>
```

`install` は追加済みのすべてのマーケットプレイスから `<name>` を解決します。2 つのマーケットプレイスが同名を提供する場合、コマンドは失敗して一覧を表示します。`--marketplace <name>` を付けて再実行してください。同名の拡張機能を異なるマーケットプレイスからインストールした場合は共存します——インストールはマーケットプレイスごとに分離されます。

組み込み拡張機能はアプリとともに自動更新されます。個人（インポート済み）拡張機能には pull する上流がありません——新しい ZIP を再インポートしてください。

## レビュー確認ゲート

マーケットプレイスのエントリが未検証（または取り消し済み）の拡張機能をインストールまたは更新するには、明示的な確認が必要です。Desktop では**拡張機能の確認**ダイアログが表示され、CLI では `--review-acknowledged` が求められ、TUI では確認ステップが表示されます。

## 拡張機能のインポート（ZIP）

ZIP パッケージは自己申告のサイドチャネルです：マーケットプレイスを介しません。

- Desktop：**拡張機能**ページ → **追加** → **拡張機能をインポート**、ZIP ファイルを選択。
- CLI：`spirit extension import <archive>`。

インポートは**個人**マーケットプレイスに未検証エントリとして登録され、同じレビュー確認ゲートを通ります。同名を再インポートすると上書きされます。インポートした拡張機能をアンインストールすると、個人マーケットプレイスのレコードも削除されます。

## マーケットプレイスの追加

- Desktop：**拡張機能**ページ → **追加** → **マーケットプレイスを追加** → **ディスクから追加**（ローカルディレクトリ）または **URL から追加**（Git リポジトリまたは HTTP インデックス URL）。
- CLI：`spirit extension marketplace add <url|path>`。

3 つのロケータ形式：

| 形式                               | 例                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------ |
| ローカルディレクトリ               | `spirit extension marketplace add ./my-marketplace`                      |
| Git リポジトリ（HTTPS または SSH） | `spirit extension marketplace add git@github.com:octocat/extensions.git` |
| HTTP インデックス URL              | `spirit extension marketplace add https://example.com`                   |

Git URL には `--git-ref <tag|branch|commit>` で ref を固定できます。デフォルトはリモートのデフォルトブランチです。ベアなサイト URL には自動で `/.spirit/marketplace.json` が補完されます。

追加したマーケットプレイスは `spirit extension marketplace list` と `spirit extension marketplace remove <name>` で管理します。Desktop ではマーケットプレイスのタブを右クリックすると削除アクションが表示されます。

<Callout type="info">
  拡張機能が宣言する能力は、パッケージ自身ではなくマーケットプレイスが裏付けます。マーケットプレイスを追加するということは、その運営者のレビューを信頼するということです——信頼できるソースだけを追加してください。
</Callout>
