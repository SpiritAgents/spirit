ルールはエージェントが常に考慮するMarkdownです。3つのスロットがあります：

| スコープ                             | パス                          |
| ------------------------------------ | ----------------------------- |
| ワークスペースのエージェントファイル | `{workspace}/AGENTS.md`       |
| ワークスペースのスピリットルール     | `{workspace}/.spirit/rule.md` |
| ユーザールール                       | `{spiritDataDir}/rule.md`     |

プロジェクトの規約を `AGENTS.md` に記述して、リポジトリを開いた人が誰でも見られるようにします。スピリット固有のメモは `.spirit/rule.md` を使用し、一般的なエージェントファイルには含めないでください。ユーザールールは、ワークスペースをまたいでフォローする設定に使用します。

スロットは **設定 → ルール** で管理します。組み込みスキル `create-rule` がルールファイルのドラフトを作成できます。[拡張機能](../develop/extensions.mdx) に同梱された rule は、その拡張機能が有効なときだけ適用され、この設定一覧には出ません。
