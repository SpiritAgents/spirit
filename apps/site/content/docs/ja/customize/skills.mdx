title: スキル

---

スキルは `SKILL.md` を含むフォルダーです。Spirit はスキルを以下の 3 つの場所から発見します:

| スコープ              | パス                                         |
| --------------------- | -------------------------------------------- |
| ユーザー              | `{spiritDataDir}/skills/{name}/SKILL.md`     |
| ワークスペース Spirit | `{workspace}/.spirit/skills/{name}/SKILL.md` |
| ワークスペース agents | `{workspace}/.agents/skills/{name}/SKILL.md` |

ターン内でスキルに言及すると、Spirit はそのユーザーメッセージにスキルの全文を添付できます。すべてのスキルをシステムプロンプトに投入することはありません。

## フロントマター

`SKILL.md` はフロントマターで始まる必要があります。`name` または `description` が欠落しているファイルは発見されません。

| フィールド    | 説明                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------- |
| `name`        | 必須。スキル名。フォルダー名と一致する必要があります。1～64文字の小文字英数字とハイフンのみ |
| `description` | 必須。短い説明                                                                              |

## 組み込みスキル

これらは Spirit に同梱されています（データディレクトリ内のファイルではありません）:

- `create-rule` — [ルール](./rules.mdx) の下書き
- `create-skill` — [スキル](./skills.mdx) の下書き
- `create-hook` — [フック](./hooks.mdx) の下書き
- `create-extension` — [拡張機能](../develop/extensions.mdx) の下書き

**設定 → スキル** でスキルを管理します。Git コミット/プッシュ/マージのチップはホスト UI であり、バンドルされたスキルではありません。[デスクトップ](../desktop.mdx) を参照してください。[拡張機能](../develop/extensions.mdx) に同梱された skills は、その拡張機能が有効なときだけ使え、この設定一覧には出ません。
