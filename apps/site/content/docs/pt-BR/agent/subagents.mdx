---
title: Subagentes
description: Delegue uma tarefa escopada a uma sessão filha, opcionalmente em um git worktree.
---

O agent pode chamar `subagent` para iniciar uma sessão filha. A filha trabalha em uma tarefa isolada e retorna apenas seu resultado final para a mãe.

## Argumentos

| Campo              | Obrigatório | Papel                                                   |
| ------------------ | ----------- | ------------------------------------------------------- |
| `task`             | sim         | O que a filha deve fazer                                |
| `success_criteria` | não         | Como a filha sabe que está pronto                       |
| `context_summary`  | não         | Contexto curto que a filha não deve ter que redescobrir |
| `files_to_inspect` | não         | Caminhos para ler primeiro                              |
| `expected_output`  | não         | Forma do resultado que a mãe quer de volta              |
| `worktree`         | não         | `true` para editar em um git worktree isolado           |

Use `worktree: true` quando a filha editar arquivos e outras filhas puderem editar ao mesmo tempo. Omita para trabalho somente leitura.

## Limites

Uma filha já em execução dentro de um worktree não pode iniciar outro worktree. O início e o fim da sessão podem executar hooks (`subagentStart` / `subagentEnd`). Você pode inspecionar sessões filhas pelo visualizador de subagente no Desktop ou `/subagent` no TUI do CLI.
