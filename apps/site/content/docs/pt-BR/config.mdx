O diretório de dados compartilhados do usuário depende da quality do build, não do diretório de aplicativos do sistema.

## Diretório de dados

Substitua com `SPIRIT_DATA_DIR`. O servidor também pode usar `SPIRIT_SERVER_DATA_DIR` (tem precedência sobre o primeiro).

| Build  | macOS / Linux                             | Windows                                               |
| ------ | ----------------------------------------- | ----------------------------------------------------- |
| Stable | `~/{{product.stable.userDataFolderName}}` | `%USERPROFILE%\{{product.stable.userDataFolderName}}` |
| Dev    | `~/{{product.dev.userDataFolderName}}`    | `%USERPROFILE%\{{product.dev.userDataFolderName}}`    |

Breaking Change: os diretórios antigos não são lidos nem migrados automaticamente. As substituições explícitas do diretório de dados continuam disponíveis. Caches do Electron, armazenamento do navegador e estado das janelas permanecem no diretório privado da plataforma.

Arquivos típicos:

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

Os binários CLI usam SPIRIT_HOME. No Unix, a instalação Stable e os dados compartilhados podem ter o mesmo diretório pai; bin/ e cli/ continuam sendo arquivos de instalação. Essa configuração não seleciona o diretório de dados compartilhados.

## config.json v2

`schemaVersion` deve ser `2`. A versão 1 é rejeitada — exclua o arquivo antigo e [reconecte um provedor](./providers.mdx).

Campos principais:

- `providerGroups` — casas conectadas, base da API, transporte, modelos
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `secondaryLanguageModel`
- `permission` — regras da lista de permissões

As chaves **não** estão neste arquivo. Elas ficam no [keyring](./security.mdx).

### permission

`permission` fixa o que comandos de shell e caminhos de arquivos individuais podem fazer, além do [nível de aprovação](./agent/approvals.mdx) da sessão. As chaves são nomes de ferramentas (`shell`, `read_file`); os valores mapeiam padrões com curingas para `allow`, `ask` ou `deny`.

```json
{
  "permission": {
    "shell": {
      "git *": "allow",
      "rm -rf *": "deny"
    }
  }
}
```

`deny` é absoluto — nenhum nível de aprovação, hook ou memória de sessão o anula. A sintaxe de padrões, a semântica de caminhos e a lista completa de ações estão em [Aprovações](./agent/approvals.mdx). Verifique regras sem executar nada: `spirit permission check --shell "git status"`.

O antigo `tool-permissions.json` (gravado pelo botão "Always Trust") está obsoleto: o código não o lê nem o grava mais, e não há migração automática. Arquivos remanescentes são inertes — exclua-os manualmente.

## `{{product.workspaceDataFolderName}}/` do workspace

| Caminho                                          | Função                                        |
| ------------------------------------------------ | --------------------------------------------- |
| `{{product.workspaceDataFolderName}}/rule.md`    | [Regra](./customize/rules.mdx) do workspace   |
| `{{product.workspaceDataFolderName}}/skills/`    | [Skills](./customize/skills.mdx) do workspace |
| `{{product.workspaceDataFolderName}}/mcp.json`   | [MCP](./customize/mcp.mdx) do workspace       |
| `{{product.workspaceDataFolderName}}/hooks.json` | [Hooks](./customize/hooks.mdx) do workspace   |

Também usado: `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## Variáveis de ambiente

| Variável                                                          | Função                                           |
| ----------------------------------------------------------------- | ------------------------------------------------ |
| `SPIRIT_DATA_DIR`                                                 | Diretório de dados                               |
| `SPIRIT_SERVER_DATA_DIR`                                          | Diretório de dados do servidor (tem precedência) |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                                 |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | Instalador do CLI                                |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | Substituições de processo do [CLI](./cli.mdx)    |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | Host Web do Desktop                              |
| `SPIRIT_TERMINAL_SHELL`                                           | Shell PTY do Desktop                             |
