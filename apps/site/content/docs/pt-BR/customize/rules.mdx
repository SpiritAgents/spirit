Regras são Markdown que o agente sempre considera. Há três espaços:

| Escopo                          | Caminho                       |
| ------------------------------- | ----------------------------- |
| Arquivo de agentes do workspace | `{workspace}/AGENTS.md`       |
| Regra Spirit do workspace       | `{workspace}/.spirit/rule.md` |
| Regra do usuário                | `{spiritDataDir}/rule.md`     |

Escreva convenções do projeto em `AGENTS.md` para que qualquer pessoa que abra o repositório as veja. Use `.spirit/rule.md` para notas específicas do Spirit que você não quer no arquivo de agentes genérico. Use a regra do usuário para preferências que o acompanham em todos os workspaces.

Gerencie espaços em **Settings → Rules**. Uma Skill integrada, `create-rule`, pode redigir um arquivo de regra para você. Uma rule empacotada em uma [extensão](../develop/extensions.mdx) vale quando essa extensão está ativada. Ela não aparece nesta lista de configurações.
