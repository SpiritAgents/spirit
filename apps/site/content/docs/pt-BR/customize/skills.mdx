Uma Skill é uma pasta com um `SKILL.md`. O {{product.name|mdx}} descobre Skills de três lugares:

| Escopo               | Caminho                                      |
| -------------------- | -------------------------------------------- | ------------------------------------------------------------------------ |
| Usuário              | `{spiritDataDir}/skills/{name}/SKILL.md`     |
| {{product.name|mdx}} do Workspace                           | `{workspace}/{{product.workspaceDataFolderName}}/skills/{name}/SKILL.md` |
| Agentes do Workspace | `{workspace}/.agents/skills/{name}/SKILL.md` |

Quando você menciona uma Skill em um turno, o {{product.name|mdx}} pode anexar seu texto completo à mensagem do usuário. Ele não despeja todas as Skills no prompt do sistema.

## Frontmatter

`SKILL.md` deve começar com Frontmatter. Um arquivo sem `name` ou `description` não é descoberto.

| Campo         | Descrição                                                                                                                        |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `name`        | Obrigatório. Nome da Skill; deve corresponder ao nome da pasta. 1–64 caracteres, apenas letras minúsculas, dígitos e hífens |
| `description` | Obrigatório. Descrição curta                                                                                                     |

## Skills Integradas

Estas vêm com o {{product.name|mdx}} (não são arquivos no seu diretório de dados):

- `create-rule` — criar um rascunho de [regra](./rules.mdx)
- `create-skill` — criar um rascunho de [Skill](./skills.mdx)
- `create-hook` — criar um rascunho de [gancho](./hooks.mdx)
- `create-extension` — criar um rascunho de [extensão](../develop/extensions.mdx)

Gerencie Skills em **Configurações → Skills**. Os chips de git commit / push / merge são da interface do host, não Skills incluídas. Veja [Desktop](../desktop.mdx). Skills empacotadas em uma [extensão](../develop/extensions.mdx) ficam disponíveis quando essa extensão está ativada. Elas não aparecem nesta lista de configurações.
