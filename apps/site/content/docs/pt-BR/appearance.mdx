---
title: Aparência
description: Tema, fontes e os dez idiomas da interface.
---

Abra **Configurações → Aparência**.

## Tema

`system`, `light` ou `dark`. Armazenado como `spirit-desktop-theme`.

## Fonte

O padrão é a fonte do sistema. Você pode alternar para uma família personalizada.

## Idiomas da interface

A interface do Desktop / CLI tem **dez** idiomas. O padrão é o chinês simplificado.

| Código  | Idioma              |
| ------- | ------------------- |
| `zh-CN` | 简体中文 (padrão)   |
| `en`    | Inglês              |
| `zh-TW` | 繁體中文            |
| `ja`    | 日本語              |
| `ko`    | 한국어              |
| `de`    | Alemão              |
| `fr`    | Francês             |
| `es`    | Espanhol            |
| `pt-BR` | Português do Brasil |
| `ru`    | Russo               |

Outras alternâncias de aparência (mica / desfoque, ponteiro) permanecem na mesma página de configurações.
