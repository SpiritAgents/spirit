O CLI é um host de terminal. Instale-o com o [script de instalação](./install/cli.mdx). Ele fala com o mesmo daemon que o [Desktop](./desktop.mdx).

## TUI

```bash
cd /path/to/your/project
spirit
```

O layout é `inline` ou `fullscreen` (`-t` / `--tui`, ou `/tui`). Modos, aprovações e Loop correspondem ao Desktop.

Comandos de barra úteis: `/help`, `/quit`, `/new`, `/continue`, `/loop`, `/model`, `/sessions`, `/rewind`, `/fork`, `/subagents`, `/approval`, `/mcp`, `/hooks`, `/rules`, `/skills`, `/extensions`.

## Não interativo

```bash
spirit -p "your prompt here"
```

Somente o texto final do assistente vai para a saída padrão. Coloque `-m`, `-a` e `-l` **antes** de `-p`. O processo falha se uma chamada precisar de aprovação ou [ask_questions](./agent/ask-questions.mdx). O modo sem cabeça expira após 30 minutos.

## Ambiente

| Variável          | Função                                                                           |
| ----------------- | -------------------------------------------------------------------------------- |
| `SPIRIT_API_KEY`  | Chave de API para este processo. Ordem: env → keyring do modelo → keyring global |
| `SPIRIT_API_BASE` | URL base da API de substituição                                                  |
| `SPIRIT_DATA_DIR` | Diretório de dados (mesmo armazenamento que o Desktop)                           |
| `SPIRIT_HOME`     | Raiz de instalação do **binário** do CLI — não o diretório de dados              |

## Daemon compartilhado

`spirit` conecta via WebSocket ao daemon do Spirit Server. Sessões, streaming, ferramentas e a fila de aprovações residem lá. O token de portador é `{spiritDataDir}/server.token` (modo `0600`). O daemon vincula `127.0.0.1` em uma porta aleatória por padrão.

`spirit serve` executa o daemon em primeiro plano. Remoto `0.0.0.0` não é um caminho de produto aberto. Consulte [Segurança](./security.mdx).

## Comandos

```
spirit [-v] [-m model] [-a approval] [-l language] [-t inline|fullscreen] [-p prompt]
spirit interactive
spirit serve
spirit model list|add|remove|use|current
spirit config show|set-base|set-image-model|clear-image-model|set-video-model|clear-video-model|key set|remove|status
spirit mcp …
spirit hooks list|validate
spirit extension list|import|remove …
```
