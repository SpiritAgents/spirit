## Provedores de modelo

O {{product.name|mdx}} não fornece serviços de modelo diretamente. Você pode conectar OpenAI, Anthropic, SpaceXAI, um gateway ou um provedor regional. Cada provedor roda no mesmo harness: ferramentas, aprovações, sessões e comportamento do workspace permanecem consistentes.

As chaves são gravadas no chaveiro do sistema sob o serviço `{{product.name}}`. Elas não são armazenadas no `config.json`.

## Um agente, dois hosts

O Desktop e a CLI compartilham um daemon local. Sessões, modelos, aprovações e credenciais ficam no mesmo diretório de dados, para que você possa iniciar uma tarefa no aplicativo e continuá-la no terminal.

2. Abra um workspace
3. Conecte um provedor
4. Peça ao agente para ler o repositório, fazer uma pequena edição e aprovar a alteração
