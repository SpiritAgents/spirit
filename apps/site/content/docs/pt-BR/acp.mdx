O ACP (Agent Client Protocol) é implementado como `spirit-acp` (`@spiritagent/acp-server`). Ele fala stdio ndJSON, compartilha o mesmo diretório de dados e chaveiro do Desktop e da CLI, e pode executar `--setup` para conectar um provedor.

**A página pública de download ainda não lista o ACP.** O {{product.name|mdx}} ainda está se preparando para listá-lo no registro ACP.

## Configuração temporária antes da listagem

Até que seja listado, instale e conclua a configuração com `npx`:

```bash
npx @spiritagent/acp-server --setup
```

Ou aponte um cliente ACP (por exemplo, Zed) para a entrada stdio:

```json
"agent_servers": {
  "{{product.name}}": {
    "command": "node",
    "args": ["path/to/packages/acp-server/dist/src/stdio-entry.js"]
  }
}
```

Autentique-se com **Run in terminal**, conclua `--setup`, depois `authenticate` e `session/new`.

| Variável               | Função                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `SPIRIT_ACP_WORKSPACE` | Raiz do espaço de trabalho (padrão é o cwd do cliente)                                |
| `SPIRIT_ACP_DATA_DIR`  | Diretório de dados; caso contrário, `SPIRIT_DATA_DIR` e depois o padrão da plataforma |
